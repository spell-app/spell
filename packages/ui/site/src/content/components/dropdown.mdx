<Section title="Usage">
  Rich data is a JS property, primitives are attributes, events are composed `ui-*` CustomEvents:

```js
const dropdown = document.querySelector("ui-dropdown")
dropdown.options = [
  { value: "1", text: "Male" },
  { value: "0", text: "Female" }
]
dropdown.addEventListener("ui-change", (event) => console.log(event.detail.value))
```
