==== /Task.spell
⟪# A task, and the checklist that holds it⟫
⟦// Something to do:  its title, and whether it's done.⟧
⟦// Each task is its own element on the page, `<task-list-task>`:⟧
⟦// a handle to drag it by, a box to tick, its title, and a button to delete it.⟧
⟦// Its checklist is one too, `<task-list-checklist>`, the tasks one under the other.⟧

[thing create_type L0]
| a «"task"» is a **draggable view**
|   [property define_property_has L1]
|   | its «"title"» is **text**
|   |   ⟦// What to do⟧
|   [property define_property_has L1]
|   | its «"done"» is yes or no
|   [property define_property_has L1]
|   | its «"order"» is **number**
|   |   ⟦// Where it sits in its checklist, from 1:  kept with it, so the order you drag the tasks into comes back⟧
|   [property quoted_type_expression L1]
|   | it «"is done"» if its **done** is _yes_    ‾value(its done)
|   [property quoted_type_expression L1]
|   | it «"is active"» if it is not done    ‾question(it is not done)

⟪## The checklist⟫

[thing create_viewable_list_type L0]
| a «"checklist"» is a **viewable list of tasks**
|   its items can be reordered immediately
|     ⟦// on the page, its tasks can be dragged to another place:  they move as the pointer does, gliding there⟧
|   [action drag_handler L1]
|   | when «a task is dropped on it»    ‾value(a task) bold(task)
|   |   ⟦// a drop has moved its tasks:  each keeps its new place⟧
|   |   keep the order    ‾call(keep the order)
|   [action to_do_something L1]
|   | to **draw** it
|   |   ⟦// Its tasks one under the other;  while it's empty, a line saying so⟧
|   |   <⟨stack⟩ spacing=«"xs"»>
|   |     <⟨if⟩ it is empty>
|   |       <⟨text⟩ color=«"grey"»>Nothing to do</⟨text⟩>
|   |     </⟨if⟩>
|   |     <⟨children⟩ />
|   |   </⟨stack⟩>
|   [action to_do_something L1]
|   | to «keep the order»
|   |   ⟦// Each task keeps its place in the list, from 1:  so the order you drag them into comes back next time⟧
|   |   [control list_iteration L2]
|   |   | for **task**, **place** in it    ‾value(it)
|   |   |   set the **order** of **task** to **place**    ‾value(the order of task) ‾value(place)

|   [action to_do_something L1]
|   | to «test a dragged order is kept»
|   |   set the **list** to **a new checklist**    ‾value(the list) ‾value(a new checklist)
|   |   set the **first** to **a new task** with **title** _"first"_    ‾value(the first) ‾value(a new task with title "first")
|   |   set the **second** to **a new task** with **title** _"second"_    ‾value(the second) ‾value(a new task with title "second")
|   |   add the **second** to the **list**    ‾value(the second) ‾value(the list)
|   |   add the **first** to the **list**    ‾value(the first) ‾value(the list)
|   |   keep the order of the **list**    ‾call(keep the order of the list)
|   |   the **order** of the **second** should be _1_    ‾value(the order of the second)
|   |   the **order** of the **first** should be _2_    ‾value(the order of the first)
|   |   the **title** of the first **task** in (the **list** sorted by its **order**) should be _"second"_    ‾value(the title of the first task in (the list sorted by its order))
[property belongs_to_one L0]
| a **task** belongs to one **checklist**
|   ⟦// a task is in one checklist at a time⟧

==== /TaskList.api.spell
⟪## Task List:  where the tasks are kept⟫
⟦// On this device, in this browser's own storage:  nobody else sees them, no server is asked, and there's no sign-in.⟧
⟦// A task saves itself as it changes:  ticking it, typing its title, or dragging it into place is kept, with no save step.⟧
⟦// Change the first line to keep them somewhere else, and nothing else changes.⟧
[thing stored_on_this_device L0]
| «my tasks» is stored on this device
a **task** lives in **my tasks**    ‾value(my tasks)

==== /TaskList.spell
⟪# Task List⟫
⟦// A to-do list:  type a task and add it, tick it off when it's done, delete it, and drag the tasks into order.⟧
⟦// Its tasks and their checklist are in Task.spell;  this file holds the app.⟧
⟦// They're kept on this device, so they're still there next time:  TaskList.api.spell says where.⟧

⟪## The app⟫
⟦// A header saying how many are left, the new task's field, then the list;  and a tour of them, its Tour button in the header.⟧

[thing create_one_of_a_kind L0]
| «task list» is an **app**
|   [property define_property_has L1]
|   | «"checklist"» is **a new checklist**
|   [property define_property_has L1]
|   | its «"draft"» is **text**
|   |   ⟦// The next task's title, as the new task's field holds it⟧
|   [property property_value_getter L1]
|   | its «"active count"» is the **length** of (**tasks** in the **checklist** where it is active)

|   [action create_hook L1]
|   | when «creating it»    ‾value(it)
|   |   ⟦// The tasks kept on this device, in their order⟧
|   |   fill the checklist    ‾call(fill the checklist)

|   [action to_do_something L1]
|   | to «fill the checklist»
|   |   ⟦// The first time, with none kept yet, a few to start with⟧
|   |   clear the **checklist**    ‾value(the checklist)
|   |   [control list_iteration L2]
|   |   | for **task** in (every **task**) sorted by its **order**    ‾value((every task) sorted by its order)
|   |   |   add it to the **checklist**    ‾value(it) ‾value(the checklist)
|   |   if the **checklist** is not empty return    ‾question(the checklist is not empty)
|   |   add the task _"Add a task above"_    ‾call(add the task "Add a task above")
|   |   add the task _"Tick it off when it's done"_    ‾call(add the task "Tick it off when it's done")
|   |   add the task _"Drag a task by its handle to move it"_    ‾call(add the task "Drag a task by its handle to move it")
|   |   add the task _"Delete one with its button"_    ‾call(add the task "Delete one with its button")
|   |   set the **done** of the first **task** in the **checklist** to _yes_    ‾value(the done of the first task in the checklist)

|   [action to_do_something L1]
|   | to «add the task (title as text)»    ‾value(title as text) bold(title) bold(text)
|   |   ⟦// A new task at the end of the list, kept on this device⟧
|   |   set **task** to **a new task** with **title** = **title**    ‾value(task) ‾value(a new task with title = title)
|   |   add **task** to the **tasks**    ‾value(task) ‾value(the tasks)
|   |   add **task** to the **checklist**    ‾value(task) ‾value(the checklist)
|   |   set the **order** of **task** to the **length** of the **checklist**    ‾value(the order of task) ‾value(the length of the checklist)

|   [action to_do_something L1]
|   | to «add the draft»
|   |   ⟦// The draft, as a new task;  the field empties⟧
|   |   if the **draft** is _""_ return    ‾value(the draft)
|   |   add the task the **draft**    ‾call(add the task the draft)
|   |   clear the **draft**    ‾value(the draft)

|   [action to_do_something L1]
|   | to «"take the tour"» with title «"Tour"», icon «"map signs"»
|   |   ⟦// A few steps through the app, pointing at each part⟧
|   |   start tour _"Task List"_

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨container⟩>
|   |     <⟨stack⟩>
|   |       <⟨stack⟩ direction=«"horizontal"» justify=«"between"»>
|   |         <⟨header⟩ level=«"2"»>Task List</⟨header⟩>
|   |         <⟨stack⟩ direction=«"horizontal"» spacing=«"sm"»>
|   |           <⟨text⟩ color=«"grey"»>
|   |             <⟨if⟩ the active count is 0>All done<⟨otherwise⟩>{the **active count**} to do</>    code({the active count})
|   |           </⟨text⟩>
|   |           <⟨action⟩ «"take the tour"» appearance=«"tertiary"» />
|   |         </⟨stack⟩>
|   |       </⟨stack⟩>
|   |       <⟨form⟩ value={it}>    code({it})
|   |         <⟨input⟩ id=«"new task"» name=«"draft"» placeholder=«"Something to do"» aria-label=«"New task"» fluid action>
|   |           <⟨button⟩ slot=«"action"» color=«"primary"» disabled={the **draft** is _""_} onClick={add the draft}>Add</⟨button⟩>    code({the draft is ""}) code({add the draft})
|   |         </⟨input⟩>
|   |       </⟨form⟩>
|   |       {draw the **checklist**}
|   |     </⟨stack⟩>
|   |     <⟨tour⟩ name=«"Task List"» summary=«"Add your tasks, tick them off and put them in order."»>
|   |       <⟨tour-step⟩ target=«"new task"»>Type something to do here, then press Add.</⟨tour-step⟩>
|   |       <⟨tour-step⟩ target=«"checklist"»>Your tasks are here. Tick one off when it's done.</⟨tour-step⟩>
|   |       <⟨tour-step⟩ target=«"checklist"»>Drag a task by its handle to move it.</⟨tour-step⟩>
|   |       <⟨tour-step⟩>That's it. Your tasks stay on this device for next time.</⟨tour-step⟩>
|   |     </⟨tour⟩>
|   |   </⟨container⟩>
