==== /MetArtworks.api.spell
⟪## The Met Museum:  every artwork in its collection, and a search of all of it⟫
⟦// A server other people run, and what it holds.  What's drawn from it is in MetArtworks.spell.⟧
⟦// `met museum` is what this wrote, from looking at the server:⟧
⟦//   spell place ingest https://collectionapi.metmuseum.org/public/collection --kind "web server" --docs https://metmuseum.github.io⟧
⟦//     --into MetArtworks.api.spell --name "met museum" --no-ai --collections "artworks=/v1/objects,artworks=/v1.1/search?q=sunflowers"⟧
⟦// `spell place update MetArtworks.api.spell` looks again, and changes only this file and MetArtworks.api.json5.⟧
⟦// Its list is only ids, over 500,000 of them:  each artwork is read whole from its own address, only when something reads it.⟧
⟦// Its search finds ids too, looking at all of each artwork, its tags too:  `every artwork matching ...`.⟧
⟦// Asked only for artworks with pictures (`hasImages=true`, written in by hand):  the rest would be read for nothing.⟧
⟦// It asks for 80 requests a second at most, in its docs:  a program keeps to that.⟧
⟦// Its search pages by "limit" and "offset", up to 500 at a time;  its list of every id takes neither, and comes whole.⟧

[thing create_place L0]
| «met museum» is a web server at «"https://collectionapi.metmuseum.org/public/collection"»
|   its id is its _"objectID"_
|   its rows are its _"objectIDs"_
|   its lists give only each one's _"objectID"_
|   its next page is asked for with _"limit"_ and _"offset"_
|   it gives up to _500_ at a time
|   check it every _30_ seconds    ‾quantity(30 seconds)
|   it takes up to _80_ requests a second
|   it searches everything with _"q"_ at _"/v1.1/search?hasImages=true"_
|   **artworks** live at _"/v1/objects"_

==== /MetArtworks.spell
⟪# Artworks from the Met⟫
⟦// Artworks of the Metropolitan Museum of Art, found by what you type:  a wall of pictures that goes on as you scroll.⟧
⟦// Every thing it shows is in MetArtworks.api.spell, as `spell place ingest` wrote it;  each type below adds to its type there,⟧
⟦// so looking again at the server never touches a line of this.⟧
⟦// Its search answers only ids:  each artwork is read from its own address as it's drawn, and no others.⟧
⟦// An artwork with no picture is left out:  the wall draws more as you scroll, so a short screen fills from the next ones.⟧

[thing create_one_of_a_kind L0]
| «met artworks» is an **app**
|   [property define_property_has L1]
|   | its «"search"» is **text**
|   [action create_hook L1]
|   | when «creating it»    ‾value(it)
|   |   set its **search** to _"sunflowers"_    ‾value(its search)
|   [property property_value_getter L1]
|   | its «"found"» is every **artwork** matching the **search**
|   |   ⟦// What the Met finds for the search, looking at all of each artwork:  ids only, each read as it's drawn⟧

|   [action to_do_something L1]
|   | to «try (words as text)»    ‾value(words as text) bold(words) bold(text)
|   |   set its **search** to **words**    ‾value(its search) ‾value(words)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨container⟩>
|   |     <⟨stack⟩ spacing=«"lg"»>
|   |       <⟨form⟩ value={it}>    code({it})
|   |         <⟨stack⟩ spacing=«"sm"»>
|   |           <⟨stack⟩ direction=«"horizontal"» wrap align=«"center"» justify=«"between"» spacing=«"sm"»>
|   |             <⟨header⟩ size=«"large"»>Artworks from the Met</⟨header⟩>
|   |             <⟨search⟩ name=«"search"» parameter=«"art"» icon=«"search"» placeholder=«"A title, an artist, a subject"» aria-label=«"Search the Met"» />
|   |           </⟨stack⟩>
|   |           <⟨toolbar⟩ appearance=«"secondary"» size=«"small"» aria-label=«"Try a search"»>
|   |             <⟨text⟩ slot=«"title"» size=«"small"» color=«"grey"»>Try</⟨text⟩>
|   |             <⟨item⟩ onClick={try _"sunflowers"_}>Sunflowers</⟨item⟩>    code({try "sunflowers"})
|   |             <⟨item⟩ onClick={try _"van gogh"_}>Van Gogh</⟨item⟩>    code({try "van gogh"})
|   |             <⟨item⟩ onClick={try _"hokusai"_}>Hokusai</⟨item⟩>    code({try "hokusai"})
|   |             <⟨item⟩ onClick={try _"armor"_}>Armor</⟨item⟩>    code({try "armor"})
|   |             <⟨item⟩ onClick={try _"cats"_}>Cats</⟨item⟩>    code({try "cats"})
|   |             <⟨item⟩ onClick={try _"egypt"_}>Egypt</⟨item⟩>    code({try "egypt"})
|   |           </⟨toolbar⟩>
|   |         </⟨stack⟩>
|   |       </⟨form⟩>
|   |       <⟨for⟩ its found as=«"cards"» layout=«"mosaic"» columns=«"4"» doubling loading=«"Asking the Met"» failed=«"The Met can't be reached just now."» empty=«"The Met has nothing for that."» />
|   |       <⟨text⟩ size=«"small"» color=«"grey"» paragraph>
|   |         From <link link=_"https://metmuseum.github.io"_>the Met Museum's API</link>, each artwork asked for as it's shown.  Press a picture to turn it over.
|   |       </⟨text⟩>
|   |     </⟨stack⟩>
|   |   </⟨container⟩>
