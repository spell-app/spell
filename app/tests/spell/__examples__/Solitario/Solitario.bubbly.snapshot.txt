[thing create_type L0]
| una «"carta"» es una **vista reversible arrastrable** 			⟦-- Una carta de la baraja⟧
|   ⟦-- Una carta dice cuáles son su rango, su palo y su color:  un mazo, una pila o el juego solo los leen.⟧
|   ⟦-- Es una vista reversible:  cada lado es una imagen de carta (abajo):  boca arriba la suya, boca abajo el dorso que comparten todas las cartas.⟧
|   ⟦-- En la página cada carta es su propio elemento, `<solitario-carta>`:  se puede arrastrar (`arrastrable`), cuando su pila la deja ir.⟧
|   [plain group define_group L1]
|   | grupo «"Rango y Palo"» ⟦-- El as es bajo:  as = 1 ... rey = 13⟧
|   |   [property define_property_has L2]
|   |   | su «"rango"» es uno de ‹as›, ‹2 ... 10›, ‹jota›, ‹dama›, ‹rey›
|   |   [property define_property_has L2]
|   |   | su «"palo"» es uno de ‹tréboles›, ‹diamantes›, ‹corazones› o ‹espadas›
|   |   [property property_value_getter L2]
|   |   | su «"color"» es uno de ‹rojo›, ‹negro›
|   |   |   _rojo_ si es un _diamante_ o es un _corazón_    ‾question(es un diamante)
|   |   |   _negro_ de lo contrario

|   |   [property quoted_type_expression L2]
