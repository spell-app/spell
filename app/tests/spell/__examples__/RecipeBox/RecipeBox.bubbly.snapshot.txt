==== /RecipeBox.spell
⟪# Recipe Box⟫
⟦// Your recipes, on cards:  find one, add one, change one as you type or on its Edit screen, remove one and undo it.⟧
⟦// Where they're kept is in RecipeBox.api.spell, and only its first line knows.⟧

⟦// Every notes box grows as you type⟧
<⟨ui-defaults⟩>
  <⟨ui-textarea⟩ grow/>
</⟨ui-defaults⟩>

⟪## A recipe:  a card you can read and change⟫

[thing reopen_type L0]
| a **recipe**
|   [action to_do_something L1]
|   | to «edit it», can't be undone
|   |   ⟦// Its Edit screen:  nothing changes until Save;  only which screen shows, so no step to undo⟧
|   |   set the **editing** of the **recipe box** to it    ‾value(the editing of the recipe box) ‾value(it)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨card⟩>
|   |     <⟨content⟩>
|   |       <⟨form⟩ value={it} class=«"recipe"»>    code({it})
|   |         <⟨field⟩ label=«"Recipe name"»>
|   |           <⟨button⟩ slot=«"actions"» class=«"edit"» icon=«"pencil"» size=«"mini"» appearance=«"transparent"» aria-label=«"Edit"» title=«"Edit"» onClick={edit it}/>    code({edit it})
|   |           <⟨button⟩ slot=«"actions"» class=«"remove"» icon=«"close"» size=«"mini"» appearance=«"transparent"» aria-label=«"Remove"» title=«"Remove"» onClick={remove it from the **recipes**}/>    code({remove it from the recipes})
|   |           <⟨input⟩ name=«"title"» class=«"title"» size=«"large"»/>
|   |         </⟨field⟩>
|   |         <⟨field⟩ label=«"Serves"» inline>
|   |           <⟨input⟩ class=«"serves"» name=«"servings"» type=«"number"» min=«"1"» labeled=«"right"» label=«"people"»/>
|   |         </⟨field⟩>
|   |         <⟨field⟩ label=«"Notes"»>
|   |           <⟨textarea⟩ name=«"notes"» rows=«"2"»/>
|   |         </⟨field⟩>
|   |       </⟨form⟩>
|   |     </⟨content⟩>
|   |   </⟨card⟩>

⟪## Its Edit screen:  a form over a draft, so nothing changes until Save⟫

[thing create_type L0]
| a «"recipe editor"» is a **view**
|   [property define_property_has L1]
|   | its «"recipe"» is a **recipe**
|   |   ⟦// The recipe being changed⟧
|   [property property_value_getter L1]
|   | its «"draft"» is a draft of its **recipe**
|   |   ⟦// A copy to change:  the recipe stays as it was until Save⟧

|   [action to_do_something L1]
|   | to «save it», can't be undone
|   |   ⟦// Every changed field, sent together:  its own undo step, Edit, as a saved thing's change is⟧
|   |   save its **draft**    ‾value(its draft)
|   |   set the **editing** of the **recipe box** to nothing    ‾value(the editing of the recipe box) ‾value(nothing)

|   [action to_do_something L1]
|   | to «cancel it», can't be undone
|   |   ⟦// Forget the copy:  the recipe never changed⟧
|   |   discard its **draft**    ‾value(its draft)
|   |   set the **editing** of the **recipe box** to nothing    ‾value(the editing of the recipe box) ‾value(nothing)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨card⟩ class=«"editor"»>
|   |     <⟨content⟩>
|   |       <⟨form⟩ value={its **draft**}>    code({its draft})
|   |         <⟨header⟩ size=«"small"»>Edit {its **recipe's title**}</⟨header⟩>    code({its recipe's title})
|   |         <⟨field⟩ label=«"Recipe name"»>
|   |           <⟨input⟩ name=«"title"» class=«"edit-title"» size=«"large"»/>
|   |         </⟨field⟩>
|   |         <⟨field⟩ label=«"Serves"» inline>
|   |           <⟨input⟩ class=«"serves"» name=«"servings"» type=«"number"» min=«"1"» labeled=«"right"» label=«"people"»/>
|   |         </⟨field⟩>
|   |         <⟨field⟩ label=«"Notes"»>
|   |           <⟨textarea⟩ name=«"notes"» rows=«"2"»/>
|   |         </⟨field⟩>
|   |       </⟨form⟩>
|   |     </⟨content⟩>
|   |     <⟨extra⟩>
|   |       <⟨button⟩ class=«"save"» size=«"small"» color=«"primary"» disabled={the **title** of its **draft** is _""_} onClick={save it}>Save</⟨button⟩>    code({the title of its draft is ""}) code({save it})
|   |       <⟨button⟩ class=«"cancel"» size=«"small"» onClick={cancel it}>Cancel</⟨button⟩>    code({cancel it})
|   |     </⟨extra⟩>
|   |   </⟨card⟩>

⟪## The box:  the card for a new recipe, then a card for each one you have⟫

[thing create_one_of_a_kind L0]
| «recipe box» is an **app**
|   [property define_property_has L1]
|   | its «"search"» is **text**
|   [property define_property_has L1]
|   | «"new recipe"» is **a new recipe** with **servings** = «4»
|   [property define_property_has L1]
|   | its «"editing"» is a **recipe**
|   |   ⟦// The recipe on its Edit screen, while one is⟧
|   [property define_menu L1]
|   | its «"box menu"» is a menu of «"undo"»

|   [action create_hook L1]
|   | when «creating it»    ‾value(it)
|   |   ⟦// With nothing kept yet, a few to start from⟧
|   |   [control if L2]
|   |   | if there are no **recipes**    ‾value(there are no recipes)
|   |   |   add (**a new recipe** with **title** _"Tomato soup"_, **servings** = _4_, **notes** = _"Roast the tomatoes first."_) to the **recipes**    ‾value(a new recipe with title "Tomato soup", servings = 4, notes = "Roast the tomatoes first.") ‾value(the recipes)
|   |   |   add (**a new recipe** with **title** _"Dal"_, **servings** = _6_, **notes** = _"Add the spices last."_) to the **recipes**    ‾value(a new recipe with title "Dal", servings = 6, notes = "Add the spices last.") ‾value(the recipes)
|   |   |   add (**a new recipe** with **title** _"Pizza Margherita"_, **servings** = _2_, **notes** = _"A very hot oven."_) to the **recipes**    ‾value(a new recipe with title "Pizza Margherita", servings = 2, notes = "A very hot oven.") ‾value(the recipes)

|   [property property_value_getter L1]
|   | its «"matches"» is
|   |   ⟦// Newest first, by when each was saved⟧
|   |   return every **recipe** where its **title** includes the **search**, filtered here, sorted by its **created**, newest first    ‾value(every recipe where its title includes the search, filtered here, sorted by its created, newest first)

|   [action to_do_something L1]
|   | to «add the new recipe»
|   |   add the **new recipe** to the **recipes**    ‾value(the new recipe) ‾value(the recipes)
|   |   set its **new recipe** to **a new recipe** with **servings** = _4_    ‾value(its new recipe) ‾value(a new recipe with servings = 4)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨container⟩>
|   |     <⟨stack⟩ direction=«"horizontal"» wrap align=«"end"» justify=«"between"»>
|   |       <⟨stack⟩ align=«"start"»>
|   |         <⟨header⟩ size=«"large"»>Recipe Box</⟨header⟩>
|   |         <⟨text⟩ color=«"grey"»>Everything you type is saved as you go.</⟨text⟩>
|   |       </⟨stack⟩>
|   |       <⟨toolbar⟩ class=«"undo"» menu=«"box menu"» aria-label=«"Recipes"»/>
|   |       <⟨form⟩ value={it} class=«"find"» fluid>    code({it})
|   |         <⟨field⟩ label=«"Search"»>
|   |           <⟨input⟩ name=«"search"» class=«"search"» icon=«"search"»/>
|   |         </⟨field⟩>
|   |       </⟨form⟩>
|   |     </⟨stack⟩>
|   |     {draw the **screen** of it}
|   |   </⟨container⟩>

|   [action draw_it L1]
|   | to **draw** its **screen**
|   |   ⟦// Its Edit screen, while a recipe is being changed;  else the cards:  its own drawing, so its `if` picks just one⟧
|   |   [control if L2]
|   |   | if its **editing**    ‾value(its editing)
|   |   |   draw (**a new recipe editor** with **recipe** = its **editing**)    ‾value(a new recipe editor with recipe = its editing)
|   |   [control else L2]
|   |   | otherwise
|   |   |   <⟨cards⟩ columns=«"3"» doubling stackable>
|   |   |     <⟨card⟩ class=«"new"»>
|   |   |       <⟨content⟩>
|   |   |         <⟨form⟩ value={its **new recipe**}>    code({its new recipe})
|   |   |           <⟨header⟩ size=«"small"»>Add a recipe</⟨header⟩>
|   |   |           <⟨field⟩ label=«"Recipe name"»>
|   |   |             <⟨input⟩ name=«"title"» class=«"draft"» size=«"large"»/>
|   |   |           </⟨field⟩>
|   |   |           <⟨field⟩ label=«"Serves"» inline>
|   |   |             <⟨input⟩ class=«"serves"» name=«"servings"» type=«"number"» min=«"1"» labeled=«"right"» label=«"people"»/>
|   |   |           </⟨field⟩>
|   |   |           <⟨field⟩ label=«"Notes"»>
|   |   |             <⟨textarea⟩ name=«"notes"» rows=«"2"»/>
|   |   |           </⟨field⟩>
|   |   |         </⟨form⟩>
|   |   |       </⟨content⟩>
|   |   |       <⟨extra⟩>
|   |   |         <⟨button⟩ class=«"add"» size=«"small"» color=«"primary"» disabled={its **new recipe's title** is _""_} onClick={add the new recipe}>Add recipe</⟨button⟩>    code({its new recipe's title is ""}) code({add the new recipe})
|   |   |       </⟨extra⟩>
|   |   |     </⟨card⟩>
|   |   |     <⟨for⟩ recipe in the matches loading=«"Finding your recipes"»>
|   |   |       <⟨empty⟩>
|   |   |         <⟨text⟩ class=«"none"» color=«"grey"»>{_"No recipes yet. Add your first one."_ if the **search** is _""_ otherwise _"No recipes match your search."_}</⟨text⟩>    code({"No recipes yet. Add your first one." if the search is "" otherwise "No recipes match your search."})
|   |   |       </⟨empty⟩>
|   |   |       <⟨failed⟩>
|   |   |         <⟨message⟩ class=«"failed"» color=«"red"»>
|   |   |           We can't reach your recipes right now.
|   |   |           <⟨button⟩ class=«"again"» onClick={try again}>Try again</⟨button⟩>    code({try again})
|   |   |         </⟨message⟩>
|   |   |       </⟨failed⟩>
|   |   |     </⟨for⟩>
|   |   |   </⟨cards⟩>
