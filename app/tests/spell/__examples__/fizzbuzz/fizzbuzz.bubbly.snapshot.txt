==== /FizzBuzz.spell
⟪# FizzBuzz⟫
⟦// Counting to 100:  fizz for every number 3 goes into, buzz for 5, fizzbuzz for both.⟧
⟦// The counting prints nothing itself:  it says what each number is, as an event, to whoever's listening.⟧
⟦// - `Console.spell` listens, and prints each one.⟧
⟦// - `Explainer.spell` listens too, and shows them on a page.⟧

[action to_do_something L0]
| to «play fizzbuzz»
|   ⟦// each number from 1 to 100, as one of four events:  fizzbuzz, fizz, buzz, or a plain number⟧
|   [control list_range_iteration L1]
|   | for **number** from _1_ to _100_
|   |   if the **number** divided by _15_ is an **integer**: trigger fizzbuzz with **number** = the **number**    ‾question(the number divided by 15 is an integer) ‾value(the number)
|   |   otherwise if the **number** divided by _3_ is an **integer**: trigger fizz with **number** = the **number**    ‾question(the number divided by 3 is an integer) ‾value(the number)
|   |   otherwise if the **number** divided by _5_ is an **integer**: trigger buzz with **number** = the **number**    ‾question(the number divided by 5 is an integer) ‾value(the number)
|   |   otherwise trigger **plain number** with **number** = the **number**    ‾value(the number)

play fizzbuzz    ‾call(play fizzbuzz)

==== /Explainer.spell
⟪# The explainer⟫
⟦// A page about FizzBuzz:  its results, drawn as the counting sends them, then how it works and where it comes from.⟧
⟦// It's FizzBuzz's second listener, beside the console:  one algorithm, two listeners.⟧
⟦// - The counting fills this page and the console at once.⟧
⟦// - Turn it off (its import's `active`) and the example runs as a plain program, printing to the console.⟧

⟪## A result⟫
⟦// One number the counting sent, and the word it got.⟧

[thing create_type L0]
| a «"result"» is a **thing**
|   [property define_property_has L1]
|   | its «"number"» is a **number**
|   [property define_property_has L1]
|   | its «"word"» is **text**
|   |   ⟦// fizz, buzz or fizzbuzz;  empty for a plain number⟧
|   [property property_value_getter L1]
|   | its «"label"» is
|   |   ⟦// What its label says:  its word, or the number itself⟧
|   |   the **number** as text if the **word** is _""_    ‾value(the number as text) ‾value(the word)
|   |   the **word** otherwise    ‾value(the word)
|   [property property_value_getter L1]
|   | its «"color"» is
|   |   ⟦// Fizz blue, buzz green, both purple⟧
|   |   _"purple"_ if the **word** is _"fizzbuzz"_    ‾value(the word)
|   |   _"blue"_ if the **word** is _"fizz"_    ‾value(the word)
|   |   _"green"_ if the **word** is _"buzz"_    ‾value(the word)
|   |   _"grey"_ otherwise

[thing create_list_type L0]
| a «"tally"» is a **list of results**
|   ⟦// Every result so far, a label each, in a row that wraps⟧
|   [action to_do_something L1]
|   | to **draw** it
|   |   [control list_iteration L2]
|   |   | for **result** in it    ‾value(it)
|   |   |   <⟨label⟩ color={the **color** of the **result**} appearance=«"basic"»>{the **label** of the **result**}</⟨label⟩>    code({the color of the result}) code({the label of the result})
|   |   show them in: <stack direction=_"horizontal"_ wrap spacing=_"xs"_></stack>    ‾value(<stack direction="horizontal" wrap spacing="xs"></stack>)

⟪## The page⟫

[thing create_one_of_a_kind L0]
| «fizzbuzz explainer» is a **page**
|   [property define_property_has L1]
|   | «"tally"» is **a new tally**
|   [property property_value_getter L1]
|   | its «"fizzes"» is the number of (**results** in the **tally** where its **word** is «"fizz"»)
|   [property property_value_getter L1]
|   | its «"buzzes"» is the number of (**results** in the **tally** where its **word** is «"buzz"»)
|   [property property_value_getter L1]
|   | its «"fizzbuzzes"» is the number of (**results** in the **tally** where its **word** is «"fizzbuzz"»)
|   [property property_value_getter L1]
|   | its «"plain numbers"» is the number of (**results** in the **tally** where its **word** is «""»)

|   [action to_do_something L1]
|   | to **draw** it
|   |   ⟦// The results first, a count of each word and a label per number, then how it works and its roots⟧
|   |   <⟨container⟩ text>
|   |     <⟨stack⟩>
|   |       <⟨header⟩ level=«"1"»>FizzBuzz</⟨header⟩>
|   |       <⟨section⟩ label=«"The results"»>
|   |         <⟨statistics⟩ widths=«"4"» size=«"mini"»>
|   |           <⟨statistic⟩ value={the **fizzes**} label=«"fizz"» color=«"blue"»/>    code({the fizzes})
|   |           <⟨statistic⟩ value={the **buzzes**} label=«"buzz"» color=«"green"»/>    code({the buzzes})
|   |           <⟨statistic⟩ value={the **fizzbuzzes**} label=«"fizzbuzz"» color=«"purple"»/>    code({the fizzbuzzes})
|   |           <⟨statistic⟩ value={the **plain numbers**} label=«"plain numbers"»/>    code({the plain numbers})
|   |         </⟨statistics⟩>
|   |         {draw the **tally**}
|   |       </⟨section⟩>
|   |       <⟨section⟩ label=«"How it works"»>
|   |         // prettier-ignore
|   |         <⟨markdown⟩>
|   |         Count from 1 to 100, and say a word in place of some of the numbers:

|   |         - a number 3 goes into exactly:  **fizz**
|   |         - a number 5 goes into exactly:  **buzz**
|   |         - a number both go into, which is any number 15 goes into:  **fizzbuzz**
|   |         - every other number:  the number itself

|   |         The order of the checks matters:  15 is checked first, because 15 is a fizz and a buzz too.

|   |         This example's counting doesn't print anything.
|   |         It sends an event for each number, `fizz`, `buzz`, `fizzbuzz` or `plain number`, carrying the number,
|   |         and whoever is listening decides what to do with it:
|   |         the console prints a line, and this page adds a label.
|   |         </⟨markdown⟩>
|   |       </⟨section⟩>
|   |       <⟨section⟩ label=«"Where it comes from"»>
|   |         // prettier-ignore
|   |         <⟨markdown⟩>
|   |         FizzBuzz began as a children's counting game in Britain, played to practise division:
|   |         players count in turn, and anyone who says a number instead of "fizz" or "buzz" is out.

|   |         It became famous among programmers in early 2007, as a test of whether someone can write code at all.
|   |         Imran Ghory suggested it as a quick screen for job interviews,
|   |         and Jeff Atwood's post "Why Can't Programmers.. Program?" spread the idea widely.
|   |         Since then it has been written in nearly every programming language.
|   |         </⟨markdown⟩>
|   |       </⟨section⟩>
|   |     </⟨stack⟩>
|   |   </⟨container⟩>

⟪## Listening⟫
⟦// The page listens itself:  each event the counting sends becomes a result in its tally.⟧

[thing reopen_type L0]
| a **fizzbuzz explainer**
|   [action to_do_something L1]
|   | to «show (word as text) for (number as a number)»    ‾value(word as text) ‾value(number as a number) bold(word) bold(text) bold(number) bold(number)
|   |   ⟦// One result more in the tally⟧
|   |   add (**a new result** with **number** = **number**, **word** = **word**) to its **tally**    ‾value(a new result with number = number, word = word) ‾value(its tally)
|   [action on L1]
|   | on fizzbuzz with **number** as a **number**
|   |   show _"fizzbuzz"_ for **number**    ‾call(show "fizzbuzz" for number)
|   [action on L1]
|   | on fizz with **number** as a **number**
|   |   show _"fizz"_ for **number**    ‾call(show "fizz" for number)
|   [action on L1]
|   | on buzz with **number** as a **number**
|   |   show _"buzz"_ for **number**    ‾call(show "buzz" for number)
|   [action on L1]
|   | on **plain number** with **number** as a **number**
|   |   show _""_ for **number**    ‾call(show "" for number)

⟪# The console⟫
⟦// One of FizzBuzz's listeners:  it prints each number as it's counted, and the word it gets.⟧

|   print **number**, _"fizzbuzz"_    ‾value(number)
[action on L0]
| on fizz with **number** as a **number**
|   print **number**, _"fizz"_    ‾value(number)
[action on L0]
| on buzz with **number** as a **number**
|   print **number**, _"buzz"_    ‾value(number)
[action on L0]
| on **plain number** with **number** as a **number**
|   print **number**    ‾value(number)
