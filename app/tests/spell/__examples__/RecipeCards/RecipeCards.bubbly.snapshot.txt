==== /RecipeCards.api.spell
⟪## Recipe Cards:  where the recipes are kept⟫
⟦// In a JSON file, in this example's own folder:  __data/recipes.json.⟧
⟦// Plain JSON any editor opens, { "recipes": [...] }:  each recipe whole, its ingredients and steps inside it.⟧
⟦// The page server writes it, the whole file at each save;  everyone using that page server shares the recipes.⟧
⟦// The shopping list isn't here:  it's Shopping List's, in its CSV file, which this project imports (__project.json5).⟧
[thing create_place L0]
| «recipe file» is a json file at «"recipes.json"»
|   check it every _30_ seconds    ‾quantity(30 seconds)

[thing create_type L0]
| a «"recipe"» is a **view**
|   it lives in **recipe file**    ‾value(recipe file)
|   [property define_property_has L1]
|   | its «"title"» is **text**
|   [property define_property_has L1]
|   | its «"serves"» is a **number**
|   |   ⟦// How many people it's written for:  the amounts are for that many⟧
|   [property define_property_has L1]
|   | its «"picture"» is **text**
|   |   ⟦// A picture's address:  one in this example's pictures folder, or any on the web⟧
|   [property define_property_has L1]
|   | its «"ingredients"» is a list of **ingredients**
|   |   ⟦// What goes in, in order:  kept inside the recipe⟧
|   [property define_property_has L1]
|   | its «"steps"» is a list of **steps**
|   |   ⟦// What to do, in order:  kept inside the recipe⟧

[thing create_type L0]
| an «"ingredient"» is a **view**
|   ⟦// One line of a recipe:  how much, of what, and where it is in the shop⟧
|   [property define_property_has L1]
|   | its «"amount"» is a **number**
|   |   ⟦// For the recipe's own number of people;  nothing for "a pinch" or "to taste"⟧
|   [property define_property_has L1]
|   | its «"unit"» is **text**
|   |   ⟦// "g", "ml", "tbsp", "cups" ...;  nothing for a count, 2 eggs⟧
|   [property define_property_has L1]
|   | its «"name"» is **text**
|   [property define_property_has L1]
|   | its «"aisle"» is **text**
|   |   ⟦// Where it is in the shop, for the shopping list⟧
|   [property define_property_has L1]
|   | its «"grams per cup"» is a **number**
|   |   ⟦// How much a cup of it weighs, so grams show as cups:  flour 125, sugar 200;  nothing for most things⟧
|   [property define_property_has L1]
|   | its «"picked"» is yes or no
|   |   ⟦// Ticked, to go on the shopping list⟧

[thing create_type L0]
| a «"step"» is a **view**
|   ⟦// One thing to do⟧
|   [property define_property_has L1]
|   | its «"instruction"» is **text**

==== /Measures.spell
⟪# Measures:  an amount in the cook's units⟫
⟦// Metric (grams and millilitres), or cups and spoons:  the same amount, shown either way.⟧
⟦// The units' sizes are Spell's own measures, e.g. "1 cup in ml" is 236.6.⟧
⟦// Grams and counts show whole;  cups and spoons to the nearest quarter, "1 1/2".⟧

[thing create_type L0]
| a «"measure"» is a **thing**
|   ⟦// How much, and in what:  what an ingredient shows, and what goes on the shopping list⟧
|   [property define_property_has L1]
|   | its «"number"» is a **number**
|   [property define_property_has L1]
|   | its «"unit"» is **text**
|   [property property_value_getter L1]
|   | its «"written"» is
|   |   ⟦// As a cook writes it:  "200 g", "1 1/2 cups", "2"⟧
|   |   if its **number** is nothing or its **number** is _0_ return _""_    ‾value(its number) ‾value(nothing) ‾value(its number)
|   |   if its **unit** is _""_ return write its **number** for a cook    ‾value(its unit) ‾call(write its number for a cook)
|   |   if its **unit** is _"cups"_ and its **number** <= _1_ return (write its **number** for a cook) && _"cup"_    ‾value(its unit) ‾value(its number) ‾call(write its number for a cook)
|   |   return (write its **number** for a cook) && its **unit**    ‾call(write its number for a cook) ‾value(its unit)

[action to_do_something L0]
| to «measure (amount as a number) in (unit as text)»    ‾value(amount as a number) ‾value(unit as text) bold(amount) bold(number) bold(unit) bold(text)
|   ⟦// Whole:  grams, millilitres, counts⟧
|   return **a new measure** with **number** = round **amount**, **unit** = **unit**    ‾value(a new measure with number = round amount, unit = unit)

[action to_do_something L0]
| to «measure (amount as a number) in quarters of (unit as text)»    ‾value(amount as a number) ‾value(unit as text) bold(amount) bold(number) bold(unit) bold(text)
|   ⟦// To the nearest quarter:  cups and spoons⟧
|   return **a new measure** with **number** = (round (**amount** * _4_)) / _4_, **unit** = **unit**    ‾value(a new measure with number = (round (amount * 4)) / 4, unit = unit)

[action to_do_something L0]
| to «measure (millilitres as a number) in spoons or cups»    ‾value(millilitres as a number) bold(millilitres) bold(number)
|   ⟦// The spoon or cup a cook would reach for⟧
|   if **millilitres** < (_1_ tbsp in ml) return measure (**millilitres** / (_1_ tsp in ml)) in quarters of _"tsp"_    ‾value(millilitres) ‾value(1 tbsp in ml) ‾call(measure (millilitres / (1 tsp in ml)) in quarters of "tsp")
|   if **millilitres** < (_1/4_ cup in ml) return measure (**millilitres** / (_1_ tbsp in ml)) in quarters of _"tbsp"_    ‾value(millilitres) ‾value(1/4 cup in ml) ‾call(measure (millilitres / (1 tbsp in ml)) in quarters of "tbsp")
|   return measure (**millilitres** / (_1_ cup in ml)) in quarters of _"cups"_    ‾call(measure (millilitres / (1 cup in ml)) in quarters of "cups")

[action to_do_something L0]
| to «write (amount as a number) for a cook»    ‾value(amount as a number) bold(amount) bold(number)
|   ⟦// A whole number, then a quarter, a half or three quarters:  1.5 is "1 1/2"⟧
|   set **quarters** to round (**amount** * _4_)    ‾value(quarters) ‾value(round (amount * 4))
|   set **whole** to (**quarters** / _4_) as an integer    ‾value(whole) ‾value((quarters / 4) as an integer)
|   set **left over** to **quarters** - **whole** * _4_    ‾value(left over) ‾value(quarters) ‾value(whole)
|   set **part** to _""_    ‾value(part)
|   if **left over** is _1_ set **part** to _"1/4"_    ‾value(left over) ‾value(part)
|   if **left over** is _2_ set **part** to _"1/2"_    ‾value(left over) ‾value(part)
|   if **left over** is _3_ set **part** to _"3/4"_    ‾value(left over) ‾value(part)
|   if **part** is _""_ return _""_ + **whole**    ‾value(part) ‾value(whole)
|   if **whole** is _0_ return **part**    ‾value(whole) ‾value(part)
|   return **whole** && **part**    ‾value(whole) ‾value(part)

[action to_do_something L0]
| to «test fractions»
|   write _1.5_ for a cook should be _"1 1/2"_    ‾call(write 1.5 for a cook)
|   write _0.25_ for a cook should be _"1/4"_    ‾call(write 0.25 for a cook)
|   write _200_ for a cook should be _"200"_    ‾call(write 200 for a cook)
|   the **written** of (measure _250_ in spoons or cups) should be _"1 cup"_    ‾value(the written of (measure 250 in spoons or cups))
|   the **written** of (measure _15_ in spoons or cups) should be _"1 tbsp"_    ‾value(the written of (measure 15 in spoons or cups))

⟪# Recipe Cards⟫
⟦// Your recipes:  pick one, set how many are eating, and every amount scales;⟧
⟦// show it in metric or in cups and spoons;  tick ingredients and add them to the shopping list.⟧
⟦// The recipes are in a JSON file, RecipeCards.api.spell says where;  the shopping list is Shopping List's own, imported.⟧

[thing create_one_of_a_kind L0]
| «recipe cards» is an **app**
|   [property define_property_has L1]
|   | its «"chosen"» is a **recipe**
|   |   ⟦// The recipe on show⟧
|   [property define_property_has L1]
|   | its «"editing"» is a **recipe**
|   |   ⟦// The recipe on its Edit screen, while one is⟧
|   [property define_property_has L1]
|   | its «"diners"» is a **number** starting at «4»
|   |   ⟦// How many are eating⟧
|   [property define_property_has L1]
|   | its «"units"» is one of ‹metric› or ‹cups›
|   |   ⟦// Grams and millilitres, or cups and spoons⟧
|   [property property_value_getter L1]
|   | its «"scale"» is
|   |   ⟦// How much more, or less, than the recipe says⟧
|   |   if its **chosen** does not exist or the **serves** of its **chosen** is _0_ return _1_    ‾question(its chosen does not exist) ‾value(the serves of its chosen)
|   |   return its **diners** / the **serves** of its **chosen**    ‾value(its diners) ‾value(the serves of its chosen)
|   [property define_property_has L1]
|   | «"aisle list"» is **a new aisle list**
