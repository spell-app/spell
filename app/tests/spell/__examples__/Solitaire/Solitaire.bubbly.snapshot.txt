==== /Card.spell
[thing create_type L0]
| a «"card"» is a **draggable two sided view** 			⟦-- A playing card⟧
|   ⟦-- A card says what its rank, suit and color are:  a deck, a pile or the game only reads them.⟧
|   ⟦-- It's a two sided view:  each side is a card image (below):  face up its own, face down the back every card shares.⟧
|   ⟦-- On the page each card is its own element, `<solitaire-card>`:  people may drag it (`draggable`), when its pile lets it go.⟧
|   [plain group define_group L1]
|   | group «"Card Rank & Suit"»
|   |   ⟦-- Ace is low:  ace = 1 ... king = 13⟧
|   |   [property define_property_has L2]
|   |   | its «"rank"» is one of ‹ace›, ‹2 ... 10›, ‹jack›, ‹queen›, ‹king›
|   |   [property define_property_has L2]
|   |   | its «"suit"» is one of ‹clubs›, ‹diamonds›, ‹hearts› or ‹spades›
|   |   [property property_value_getter L2]
|   |   | its «"color"» is one of ‹red›, ‹black›
|   |   |   _red_ if it is a _diamond_ or it is a _heart_    ‾question(it is a diamond) ‾question(it is a heart)
|   |   |   _black_ otherwise

|   [plain group define_group L1]
|   | group «"Aliases"»
|   |   ⟦-- Spell for identifying cards⟧
|   |   [property quoted_type_expression L2]
|   |   | it «"is a face card"» if its **rank** is _jack_, _queen_ or _king_  ⟦-- e.g. "the card is a face card"⟧    ‾value(its rank)
|   |   [property quoted_type_expression L2]
|   |   | it «"is a number card"» if it is not a face card    ‾question(it is not a face card)
|   |   [property quoted_property_formula L2]
|   |   | it «"is the (rank) of (suit)"»  ⟦-- e.g. the card is the two of spades⟧
|   |   
|   [plain group define_group L1]
|   | group «"Names"» 								⟦-- identifying a card⟧
|   |   [property property_value_getter L2]
|   |   | its «"name"» is its **rank** && «"of"» && its **suit**
|   |   [property property_value_getter L2]
|   |   | its «"value"» is the position of its **rank**
|   |   [property property_value_getter L2]
|   |   | its «"symbol"» is
|   |   |   _"♣"_ if it is a _club_    ‾question(it is a club)
|   |   |   _"♦"_ if it is a _diamond_    ‾question(it is a diamond)
|   |   |   _"♥"_ if it is a _heart_    ‾question(it is a heart)
|   |   |   _"♠"_ otherwise
|   |   [property property_value_getter L2]
|   |   | its «"short name"» is
|   |   |   ⟦-- Its short name:  Q♠↓ is the queen of spades, face down⟧
|   |   |   **letter** is _10_ if its **value** is _10_ otherwise the first **letter** of its **rank** as uppercase    ‾value(letter) ‾value(its value) ‾value(the first letter of its rank as uppercase)
|   |   |   **arrow** is _"↑"_ if it is face up otherwise _"↓"_    ‾value(arrow) ‾question(it is face up)
|   |   |   return **letter** + its **symbol** + **arrow**    ‾value(letter) ‾value(its symbol) ‾value(arrow)

|   [plain group define_group L1]
|   | group «"Drawing"»
|   |   [action draw_it L2]
|   |   | to **draw** its **front**
|   |   |   <⟨card-image⟩ card={it} />    code({it})
|   |   [action draw_it L2]
|   |   | to **draw** its **back**
|   |   |   <⟨card-image⟩ direction=down />

|   |   [action to_do_something L2]
|   |   | to «test card setup»
|   |   |   get **a new card** whose **rank** is _queen_, **suit** is _spades_ and **direction** is _down_    ‾value(a new card whose rank is queen, suit is spades and direction is down)
|   |   |   its **name** should be _"queen of spades"_    ‾value(its name)
|   |   |   its **color** should be _black_    ‾value(its color)
|   |   |   its **value** should be _12_    ‾value(its value)
|   |   |   its **short name** should be _"Q♠↓"_    ‾value(its short name)
|   |   |   it is a face card should be _yes_    ‾question(it is a face card)
|   |   |   it is a _spade_ should be _yes_    ‾question(it is a spade)
|   |   |   it is a _club_ should be _no_    ‾question(it is a club)
|   |   |   it is a _queen_ should be _yes_    ‾question(it is a queen)
|   |   |   it is a _2_ should be _no_    ‾question(it is a 2)
|   |   |   it is the queen of spades should be _yes_    ‾question(it is the queen of spades)
|   |   |   it is the queen of clubs should be _no_    ‾question(it is the queen of clubs)

|   |   |   turn it over    ‾value(it)
|   |   |   it is face up should be _yes_    ‾question(it is face up)
|   |   |   its **short name** should be _"Q♠↑"_    ‾value(its short name)

|   |   |   set **seven** to **a new card** whose **rank** is _7_ and **suit** is _hearts_    ‾value(seven) ‾value(a new card whose rank is 7 and suit is hearts)
|   |   |   **seven** is a number card should be _yes_    ‾question(seven is a number card)
|   |   |   the **color** of **seven** should be _red_    ‾value(the color of seven)

==== /Pile.spell
[thing create_viewable_list_type L0]
| a «"pile"» is a **viewable**, **droppable list of cards**
|   ⟦-- A pile of cards, e.g. in a game like solitaire⟧
|   ⟦-- A card can only be in one pile at a time⟧
|   [property define_property_has L1]
|   | its «"layout"» is one of ‹stacked› or ‹vertical›
|   |   ⟦// How its cards lie:  on top of each other, or down a column -- styles.css⟧
|   [property property_value_getter L1]
|   | its «"color"» is
|   |   _"none"_ if it is empty    ‾question(it is empty)
|   |   the **color** of its last **card** otherwise    ‾value(the color of its last card)
|   [property property_value_getter L1]
|   | its «"value"» is
|   |   _0_ if it is empty    ‾question(it is empty)
|   |   otherwise the **value** of its last **card**    ‾value(the value of its last card)
|   [property property_value_getter L1]
|   | its «"short name"» is
|   |   ⟦// Its id, then its cards' short names:  stock: Q♠↑ 7♥↓⟧
|   |   set **summary** to its **id** + _":"_    ‾value(summary) ‾value(its id)
|   |   [control list_iteration L2]
|   |   | for **card** in the **pile**    ‾value(the pile)
|   |   |   set **summary** to **summary** + _" "_ + the **short name** of the **card**    ‾value(summary) ‾value(summary) ‾value(the short name of the card)
|   |   return **summary**    ‾value(summary)

|   [action drag_handler L1]
|   | when «a card is dropped»    ‾value(a card) bold(card)
|   |   move the **card** to the **pile**    ‾call(move the card to the pile)

|   [action to_do_something L1]
|   | to «move a card to a pile»    ‾value(a card) ‾value(a pile) bold(card) bold(pile)
|   |   ⟦// The card, and every card on it, onto the pile, if the piles' rules let it go and take it⟧
|   |   ⟦// - refused, nothing moves, and there's nothing to undo⟧
|   |   ⟦// - a game adds its own steps after it:  `after moving a card to a pile`⟧
|   |   cancel if the **card's pile** cannot give it up    ‾question(the card's pile cannot give it up)
|   |     or the **pile** cannot take it    ‾question(the pile cannot take it)
|   |   [control list_iteration L2]
|   |   | for **card** in **cards** in the **card's pile** starting with the **card**    ‾value(cards in the card's pile starting with the card)
|   |   |   add it to the **pile**    ‾value(it) ‾value(the pile)
