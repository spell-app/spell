# T**arjetas de** estudio
⟦// Un mazo de tarjetas para aprender:  una palabra en inglés por delante, lo que significa por detrás.⟧
⟦// Haz clic en la tarjeta, o en Mostrar la respuesta, para voltearla, y luego di si la sabías:⟧
⟦// la puntuación lleva la cuenta, y la siguiente tarjeta sale al azar.⟧
⟦// La tarjeta es de este proyecto, en `Tarjeta.es.spell`;  este archivo tiene el juego, y sus palabras.⟧

[thing create_one_of_a_kind L0]
| «juego» es una **aplicación**
|   [property define_property_has L1]
|   | «"mazo"» es **un nuevo mazo**
|   [property define_property_has L1]
|   | su «"tarjeta"» es una **tarjeta**
|   |   ⟦// La tarjeta que se ve⟧
|   [property define_property_has L1]
|   | su «"acertadas"» es un **número**
|   |   ⟦// Cuántas sabías⟧
|   [property define_property_has L1]
|   | su «"intentadas"» es un **número**
|   |   ⟦// Cuántas has intentado⟧
|   [property property_value_getter L1]
|   | su «"puntuación"» es
|   |   ⟦// Lo que dice la barra de herramientas⟧
|   |   _"Aún no has intentado ninguna"_ si las **intentadas** es _0_    ‾value(las intentadas)
|   |   _"[acertadas] de [intentadas] bien"_ de lo contrario

|   [plain group define_group L1]
|   | grupo «"Jugar"»
|   |   [action to_do_something L2]
|   |   | para «sacar otra»
|   |   |   ⟦// Una tarjeta del mazo al azar, con la palabra arriba:  nunca la que se acaba de ver⟧
|   |   |   poner **otras** a **tarjetas** en el **mazo** donde no es la **tarjeta** de **juego**    ‾value(otras) ‾value(tarjetas en el mazo donde no es la tarjeta de juego)
|   |   |   poner la **tarjeta** a una **tarjeta** al azar de **otras**    ‾value(la tarjeta) ‾value(una tarjeta al azar de otras)
|   |   |   voltear la **tarjeta** boca arriba    ‾value(la tarjeta)
|   |   [action to_do_something L2]
|   |   | para «mostrar la respuesta»
|   |   |   atajo _espacio_
|   |   |   voltear la **tarjeta**    ‾value(la tarjeta)
|   |   [action to_do_something L2]
|   |   | para «"decir que la sabía"» con título «"La sabía"», icono «"check"»
|   |   |   ⟦// Se cuenta, y luego la siguiente tarjeta⟧
|   |   |   atajo _S_
|   |   |   poner las **acertadas** a las **acertadas** + _1_    ‾value(las acertadas) ‾value(las acertadas)
|   |   |   poner las **intentadas** a las **intentadas** + _1_    ‾value(las intentadas) ‾value(las intentadas)
|   |   |   sacar otra    ‾call(sacar otra)
|   |   [action to_do_something L2]
|   |   | para «"decir que no la sabía"» con título «"No la sabía"», icono «"close"»
|   |   |   atajo _N_
|   |   |   poner las **intentadas** a las **intentadas** + _1_    ‾value(las intentadas) ‾value(las intentadas)
|   |   |   sacar otra    ‾call(sacar otra)
|   |   [action to_do_something L2]
|   |   | para «"empezar de nuevo"» con icono «"redo"»
|   |   |   limpiar las **acertadas**    ‾value(las acertadas)
|   |   |   limpiar las **intentadas**    ‾value(las intentadas)
|   |   |   sacar otra    ‾call(sacar otra)
|   |   [property define_menu L2]
|   |   | su «"menú del juego"» es un menú de «"empezar de nuevo"»

|   |   [action draw_it L2]
|   |   | para **dibujarlo**
|   |   |   ⟦// La barra de herramientas con la puntuación, la tarjeta, y luego lo que puedes hacer:  voltearla, o decir cómo te fue⟧
|   |   |   <⟨contenedor⟩ texto>
|   |   |     <⟨pila⟩>
|   |   |       <⟨barra-herramientas⟩ menu=«"menú del juego"» aria-label=«"Juego"» encogible>
|   |   |         <⟨texto⟩ slot=«"titulo"» tamano=«"grande"»>Tarjetas de estudio</⟨texto⟩>

|   |   |           <⟨bot⟩ón color=«"negativo"» apariencia=«"básico"» icono=«"close"» onClick={decir que no la sabía}>No la sabía</⟨bot⟩ón>    code({decir que no la sabía})
|   |   |         </>
|   |   |       </⟨pila⟩>

|   |   |   </⟨contenedor⟩>
