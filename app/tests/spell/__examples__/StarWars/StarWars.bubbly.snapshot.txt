==== /StarWars.api.spell
⟪## Star Wars:  where it all lives⟫
⟦// A server other people run, and what it holds.  What's drawn and done with it is in StarWars.spell;⟧
⟦// the pictures and what they're of come from Wikipedia, in Wikipedia.api.spell.⟧
⟦// `star wars` is what this wrote, from looking at the server:⟧
⟦//   spell place ingest https://swapi.py4e.com/api --into StarWars.api.spell --name "star wars"⟧
⟦// `spell place update StarWars.api.spell` looks again, and changes only this file and StarWars.api.json5.⟧
⟦// A height, a mass and a diameter say their units, cm, kg and km, as swapi's docs give them:⟧
⟦// so each shows in the reader's own, 5 ft 8 in in the US.⟧
⟦//⟧
⟦// Star Wars belongs to Lucasfilm and Disney.⟧
⟦// It's asked for as it runs, and kept only on the device of whoever's looking, until 5am;⟧
⟦// the page says where it comes from.⟧

[thing create_place L0]
| «star wars» is a web server at «"https://swapi.py4e.com/api"»
|   its id is its _"url"_
|   its rows are its _"results"_
|   its next page is its _"next"_
|   it writes names like _"hair_color"_
|   it searches **names** and **titles** with _"search"_
|   check it once a day at _5_am
|   keep a copy on this device
|   **characters** live at _"/people/"_
|   **planets** live at _"/planets/"_
|   **films** live at _"/films/"_
|   **species** live at _"/species/"_
|   **vehicles** live at _"/vehicles/"_
|   **starships** live at _"/starships/"_

==== /Wikipedia.api.spell
⟪## Wikipedia:  a page each, by its name.  Not every name has one⟫
⟦// A server other people run:  what Star Wars shows of a character, a planet or a ship, and its picture.⟧
⟦// `wikipedia` is what this wrote, from reading a few pages by name, as there's no list of them all:⟧
⟦//   spell place ingest https://en.wikipedia.org/api/rest_v1 --kind "web server" --into Wikipedia.api.spell⟧
⟦//     --name wikipedia --collections "wiki pages=/page/summary/{name}" --samples "Luke Skywalker,Tatooine,Millennium Falcon"⟧
⟦// `spell place update Wikipedia.api.spell` looks again, by the same names, and changes only this file and Wikipedia.api.json5.⟧
⟦// A wiki page's "about" and "summary" are Star Wars' words for Wikipedia's "description" and "extract".⟧
⟦//⟧
⟦// Its words belong to Wikipedia's writers.  They're asked for as it runs, never kept here, and the page says so.⟧

[thing create_place L0]

|   its id is its _"title"_
|   check it once a day
|   it writes names like _"wikibase_item"_
|   **wiki pages** are found at _"/page/summary/{name}"_

⟪# Star Wars⟫
⟦// A guide to the galaxy, what it draws and does.  Every thing it shows is in StarWars.api.spell, as `spell place ingest` wrote it:⟧
⟦// say what a field links to, and reading it follows the link, `the name of its homeworld`.⟧
⟦// Each type below adds to its type there, with `<extend>`:  so looking again at the server never touches a line of this.⟧

[thing create_one_of_a_kind L0]
| «guide» is an **app**
|   [property define_property_has L1]
|   | its «"tab"» is **text**
|   [property define_property_has L1]
|   | its «"search"» is **text**
|   [action create_hook L1]
|   | when «creating it»    ‾value(it)
|   |   set its **tab** to _"films"_    ‾value(its tab)
|   |   set its **search** to _""_    ‾value(its search)
|   [property define_property_has L1]
|   | its «"showing"» is a **thing**
|   [property define_property_has L1]
|   | «"trail"» is a new list of **things**
|   [property define_property_has L1]
|   | its «"playing"» is a **film**
|   [property define_property_has L1]
|   | its «"jumping"» is yes or no

|   [property property_value_getter L1]
|   | its «"found"» is
|   |   ⟦// Whatever's found:  the film, character, planet, ship or anything else with that in its name⟧
|   |   set **matches** to a new list of **things**    ‾value(matches) ‾value(a new list of things)
|   |   [control list_iteration L2]
|   |   | for **film** in every **film** where its **title** includes the **guide's search**    ‾value(every film where its title includes the guide's search)
|   |   |   add the **film** to **matches**    ‾value(the film) ‾value(matches)
|   |   [control list_iteration L2]
|   |   | for **character** in every **character** where its **name** includes the **guide's search**    ‾value(every character where its name includes the guide's search)
|   |   |   add the **character** to **matches**    ‾value(the character) ‾value(matches)
|   |   [control list_iteration L2]
|   |   | for **planet** in every **planet** where its **name** includes the **guide's search**    ‾value(every planet where its name includes the guide's search)
|   |   |   add the **planet** to **matches**    ‾value(the planet) ‾value(matches)
|   |   [control list_iteration L2]
|   |   | for **starship** in every **starship** where its **name** includes the **guide's search**    ‾value(every starship where its name includes the guide's search)
|   |   |   add the **starship** to **matches**    ‾value(the starship) ‾value(matches)
|   |   [control list_iteration L2]
|   |   | for **vehicle** in every **vehicle** where its **name** includes the **guide's search**    ‾value(every vehicle where its name includes the guide's search)
|   |   |   add the **vehicle** to **matches**    ‾value(the vehicle) ‾value(matches)
|   |   [control list_iteration L2]
|   |   | for **one** in every **species** where its **name** includes the **guide's search**    ‾value(every species where its name includes the guide's search)
|   |   |   add the **one** to **matches**    ‾value(the one) ‾value(matches)
|   |   return **matches**    ‾value(matches)

|   [action to_do_something L1]
|   | to «go back»
|   |   [control if L2]
|   |   | if its **trail** is empty    ‾question(its trail is empty)
|   |   |   set its **showing** to nothing    ‾value(its showing) ‾value(nothing)
|   |   |   return
|   |   set its **showing** to the last **item** of its **trail**    ‾value(its showing) ‾value(the last item of its trail)
|   |   remove the last **item** of its **trail**    ‾value(its trail)
|   |   scroll to the top

|   [action to_do_something L1]
|   | to «go to (where as text)»    ‾value(where as text) bold(where) bold(text)
|   |   set its **tab** to **where**    ‾value(its tab) ‾value(where)
|   |   set its **search** to _""_    ‾value(its search)
|   |   set its **showing** to nothing    ‾value(its showing) ‾value(nothing)
|   |   clear its **trail**    ‾value(its trail)
|   |   scroll to the top

|   [action to_do_something L1]
|   | to «play the opening»
|   |   set its **playing** to the first **film**    ‾value(its playing) ‾value(the first film)

|   [action to_do_something L1]
|   | to «punch it»
|   |   ⟦// A jump to light speed, and wherever it lands⟧
|   |   set its **jumping** to _yes_    ‾value(its jumping)
|   |   set **landing** to a random **character** in (every **character**)    ‾value(landing) ‾value(a random character in (every character))
|   |   pause for _2600_ msec    ‾quantity(2600 msec)
|   |   open **landing**    ‾call(open landing)
|   |   set its **jumping** to _no_    ‾value(its jumping)

|   | to **draw** it
