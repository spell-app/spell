==== /Statusphere.spell
⟪# Statusphere⟫
⟦// Bluesky's example app, in Spell:  set your status, an emoji, and see everyone's as they arrive.⟧
⟦// Each status is a record in its owner's own atmosphere account, in the shape Statusphere's Lexicon says:  Status.spell.⟧

⟦// Every emoji to pick is a big, plain button⟧
<⟨ui-defaults⟩>
  <⟨ui-button⟩ size=«"large"» appearance=«"basic"»/>
</⟨ui-defaults⟩>

⟪## A status:  the emoji, who set it, and when⟫

[thing reopen_type L0]
| a **status**
|   [property property_value_getter L1]
|   | its «"who"» is
|   |   ⟦// Its owner's handle, once their account says so;  else the account itself⟧
|   |   set **account** to its **owner**    ‾value(account) ‾value(its owner)
|   |   set **person** to the first **person** in everyone here where its **id** is **account**    ‾value(person) ‾value(the first person in everyone here where its id is account)
|   |   [control if L2]
|   |   | if **person** is nothing    ‾value(person) ‾value(nothing)
|   |   |   return **account**    ‾value(account)
|   |   return **person's name**    ‾value(person's name)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨stack⟩ direction=«"horizontal"» align=«"center"»>
|   |     <⟨text⟩ size=«"big"»>{its **status**}</⟨text⟩>    code({its status})
|   |     <⟨text⟩>@{its **who**}</⟨text⟩>    code({its who})
|   |     <⟨text⟩ color=«"grey"» size=«"small"»>{its **created at**}</⟨text⟩>    code({its created at})
|   |   </⟨stack⟩>

⟪## The app:  the emoji to pick, then everyone's statuses, newest first⟫

[thing create_one_of_a_kind L0]
| «statusphere» is an **app**
|   [property property_value_getter L1]
|   | its «"recent"» is
|   |   ⟦// Newest first:  by when each was set⟧
|   |   return every **status** sorted by its **created**, newest first    ‾value(every status sorted by its created, newest first)

|   [action to_do_something L1]
|   | to «post (emoji as text)»    ‾value(emoji as text) bold(emoji) bold(text)
|   |   ⟦// Your status:  a new record in your own account, as Statusphere writes one⟧
|   |   add (**a new status** with **status** = **emoji**, **created at** = **a new date**) to the **statuses**    ‾value(a new status with status = emoji, created at = a new date) ‾value(the statuses)

|   [action to_do_something L1]
