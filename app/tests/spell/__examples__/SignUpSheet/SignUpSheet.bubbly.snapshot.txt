==== /SignUpSheet.api.spell
⟪## Sign-Up Sheet:  where a picnic's sign-ups are kept⟫
⟦// The master sheet is in the picnic's private space:  only its organizers read it, notes and all.⟧
⟦// Anyone in the picnic's shared space signs up here all the same, and changes only their own row.⟧
⟦// Each shift takes two people:  two asking for the last place at once, one gets it, the other is told it's gone.⟧
⟦// Its tickets are kept here too:  the picnic has 40, each attendee asks for as many as their row says, and a ticket⟧
⟦// an organizer confirms lets its guest into the attendees' space, where the day's details are.⟧
⟦// Your event's sheet names its own spaces on the next lines:  "picnic@rs" is the Rock Society's picnic.⟧
[thing create_place L0]
| «sign up sheet» is a data folder at «"picnic@rs/__private/signups"»
|   open to sign-ups from _"picnic@rs/sheet"_
|   only its **attendees** add rows
|   at most _2_ rows for each **shift**
|   at most _40_ rows for each **event**
|   each person asks for at most their _"invitations"_ **tickets**
|   confirmed **tickets** join _"picnic@rs/__attendees"_
|   check it every _30_ seconds

[thing projection_of L0]
| the «published sheet» is a projection of the **sign up sheet**
|   ⟦// What everyone in the picnic sees:  who's on which shift, never an organizer's note.⟧
|   into _"picnic@rs/sheet"_
|   showing each **row**'s **person** and **shift**
|   **published volunteers** live at _"volunteers"_
|   check it every _30_ seconds

[thing create_type L0]
| a «"volunteer"» is a **thing**
|   it lives in the **sign up sheet**    ‾value(the sign up sheet)
|   [property define_property_has L1]
|   | its «"person"» is **text**
|   [property define_property_has L1]
|   | its «"shift"» is **text**
|   [property define_property_has L1]
|   | its «"note"» is **text**

⟦// Who may sign up, and how many invitations each may ask for:  the organizers work it out from their standing and⟧
⟦// their shifts ("work out the invitations", on the page).⟧
[thing create_type L0]
| an «"attendee"» is a **thing**
|   it lives in the **sign up sheet**    ‾value(the sign up sheet)
|   [property define_property_has L1]
|   | its «"person"» is **text**
|   [property define_property_has L1]
|   | its «"standing"» is **text**
|   [property define_property_has L1]
|   | its «"invitations"» is a **number**

[thing create_type L0]

⟪# Sign-Up Sheet⟫
⟦// A picnic's sign-up sheet:  pick a shift and sign up, then see yourself on the published sheet.⟧
⟦// Where it's all kept is in SignUpSheet.api.spell, and only its first lines know.⟧
⟦// Then your invitations:  ask for a ticket for a guest, as many as yours allow.⟧
⟦// The organizers' part shows only to them:  the master sheet with its notes, the tickets to confirm, and who may sign up.⟧

⟪## The page:  sign up, the published sheet, then the organizers' part⟫

[thing create_one_of_a_kind L0]
| «sign up page» is an **app**
|   [property define_property_has L1]
|   | «"new volunteer"» is **a new volunteer**
|   [property define_property_has L1]
|   | «"new attendee"» is **a new attendee**
|   [property define_property_has L1]
|   | «"new ticket"» is **a new ticket**
|   [property property_value_getter L1]
|   | its «"counts"» is every **message** where its **thread** is «"invitations"»
|   [property define_property_has L1]
|   | «"new letter"» is **a new message**

|   [action to_do_something L1]
|   | to «take the shift»
|   |   set the **person** of the **new volunteer** to their **id**    ‾value(the person of the new volunteer) ‾value(their id)
|   |   add the **new volunteer** to the **volunteers**    ‾value(the new volunteer) ‾value(the volunteers)
|   |   set its **new volunteer** to **a new volunteer**    ‾value(its new volunteer) ‾value(a new volunteer)

|   [action to_do_something L1]
|   | to «take setup»
|   |   set the **shift** of the **new volunteer** to _"setup"_    ‾value(the shift of the new volunteer)
|   |   take the shift    ‾call(take the shift)

|   [action to_do_something L1]
|   | to «take serving»
|   |   set the **shift** of the **new volunteer** to _"serving"_    ‾value(the shift of the new volunteer)
|   |   take the shift    ‾call(take the shift)

|   [action to_do_something L1]
|   | to «take cleanup»
|   |   set the **shift** of the **new volunteer** to _"cleanup"_    ‾value(the shift of the new volunteer)
|   |   take the shift    ‾call(take the shift)

|   [action to_do_something L1]
|   | to «ask for the ticket»
|   |   set the **person** of the **new ticket** to their **id**    ‾value(the person of the new ticket) ‾value(their id)
|   |   set the **event** of the **new ticket** to _"picnic"_    ‾value(the event of the new ticket)
|   |   add the **new ticket** to the **tickets**    ‾value(the new ticket) ‾value(the tickets)
|   |   set its **new ticket** to **a new ticket**    ‾value(its new ticket) ‾value(a new ticket)

|   [action to_do_something L1]
|   | to «work out the invitations»
|   |   ⟦// Two for a member, one for a guest, and one more for each shift they took⟧
|   |   [control list_iteration L2]
|   |   | for each **attendee** in every **attendee**    ‾value(every attendee)
|   |   |   set **shifts** to the number of **volunteers** where its **person** is the **person** of **attendee**    ‾value(shifts) ‾value(the number of volunteers where its person is the person of attendee)
|   |   |   set the **invitations** of **attendee** to **shifts** + _1_    ‾value(the invitations of attendee) ‾value(shifts)
|   |   |   [control if L3]
|   |   |   | if the **standing** of **attendee** is _"member"_    ‾value(the standing of attendee)
|   |   |   |   set the **invitations** of **attendee** to **shifts** + _2_    ‾value(the invitations of attendee) ‾value(shifts)

|   [action to_do_something L1]
|   | to «send the letter»
|   |   ⟦// The picnic's letter to every attendee:  a pointer to its page in their inboxes, which reads what's theirs as each one opens it⟧
|   |   set **everyone** to _""_    ‾value(everyone)
|   |   [control list_iteration L2]
|   |   | for each **attendee** in every **attendee**    ‾value(every attendee)
|   |   |   set **everyone** to **everyone** + the **person** of **attendee** + _", "_    ‾value(everyone) ‾value(everyone) ‾value(the person of attendee)
|   |   set the **recipients** of the **new letter** to **everyone**    ‾value(the recipients of the new letter) ‾value(everyone)
|   |   set the **text** of the **new letter** to _"Your letter for the picnic"_    ‾value(the text of the new letter)
|   |   set the **page** of the **new letter** to _"picnic@rs/PicnicLetter"_    ‾value(the page of the new letter)
|   |   set the **title** of the **new letter** to _"The Picnic:  your letter"_    ‾value(the title of the new letter)
|   |   set the **line** of the **new letter** to _"The day's details, your shifts, and your invitations"_    ‾value(the line of the new letter)
|   |   add the **new letter** to the **messages**    ‾value(the new letter) ‾value(the messages)
|   |   set its **new letter** to **a new message**    ‾value(its new letter) ‾value(a new message)

|   [action to_do_something L1]
|   | to «add the new attendee»
|   |   add the **new attendee** to the **attendees**    ‾value(the new attendee) ‾value(the attendees)
|   |   set its **new attendee** to **a new attendee**    ‾value(its new attendee) ‾value(a new attendee)

|   [action to_do_something L1]
