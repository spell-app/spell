⟪# Lista de tareas⟫
⟦// Una lista de cosas por hacer:  agrega una tarea, márcala, filtra la lista, y edita juntas las tareas seleccionadas.⟧
⟦// Sus tareas son la `tarea` de este proyecto, en Tarea.es.spell;  este archivo tiene su lista, y la aplicación.⟧
⟦// Se guardan en este dispositivo, así que siguen ahí la próxima vez:  ListaDeTareas.api.es.spell dice dónde.⟧

⟪## La agenda⟫
⟦// Las tareas, cada una un elemento propio dentro de ella:  `<lista-de-tareas-agenda>`, alrededor de sus `<lista-de-tareas-tarea>`.⟧

|   |   [property quoted_property_formula L2]
|   |   | «"está mostrando (mostrando)"»

|   sus elementos se pueden reordenar de inmediato

|   [action drag_handler L1]
|   | cuando «una tarea se suelta sobre ella»    ‾value(una tarea) bold(tarea)
|   |   ⟦// soltar movió sus tareas:  cada una guarda su nuevo lugar⟧
|   |   guardar el orden    ‾call(guardar el orden)
|   [action draw_it L1]
|   | para **dibujar** cada **elemento**
|   |   ⟦// cada tarea, salvo que el filtro la oculte⟧

|   |   si está mostrando hechas y la **tarea** está pendiente devolver nada    ‾question(está mostrando hechas) ‾question(la tarea está pendiente) ‾value(nada)
|   |   devolver dibujar la **tarea**    ‾value(la tarea)

|   | para **dibujar** eso

|   |     </⟨si⟩>

|   |   </⟨pila⟩>

|   |   |   poner el **orden** de la **tarea** al **lugar**    ‾value(el orden de la tarea) ‾value(lugar)

|   [action to_do_something L1]

|   |   agregar (**una nueva tarea** con **título** _"b"_) a la **lista**    ‾value(una nueva tarea con título "b") ‾value(la lista)
|   |   el **largo** de (**tareas** en la **lista** donde está pendiente) debería ser _1_    ‾value(el largo de (tareas en la lista donde está pendiente))

|   |   poner la **segunda** a **una nueva tarea** con **título** _"segunda"_    ‾value(la segunda) ‾value(una nueva tarea con título "segunda")
