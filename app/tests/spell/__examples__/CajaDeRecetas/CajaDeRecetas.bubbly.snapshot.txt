⟪## Su pantalla de edición:  un formulario sobre un borrador, así que nada cambia hasta Guardar⟫

[thing create_type L0]
| un «"editor de receta"» es una **vista**
|   [property define_property_has L1]
|   | su «"receta"» es una **receta**
|   |   ⟦// La receta que se está cambiando⟧
|   [property property_value_getter L1]
|   | su «"borrador"» es un borrador de su **receta**
|   |   ⟦// Una copia para cambiar:  la receta sigue igual hasta Guardar⟧

|   [action to_do_something L1]
|   | para «aceptar los cambios», no se puede deshacer
|   |   ⟦// Todos los campos cambiados, enviados juntos⟧
|   |   guardar su **borrador**    ‾value(su borrador)
|   |   fijar el **editando** de la **caja de recetas** a nada    ‾value(el editando de la caja de recetas) ‾value(nada)

|   [action to_do_something L1]
|   | para «olvidar los cambios», no se puede deshacer
|   |   ⟦// Olvida la copia:  la receta no cambió⟧
|   |   descartar su **borrador**    ‾value(su borrador)
|   |   fijar el **editando** de la **caja de recetas** a nada    ‾value(el editando de la caja de recetas) ‾value(nada)

|   [action draw_it L1]
|   | para **dibujar** eso
|   |   <⟨tarjeta⟩ class=«"editor"»>
|   |     <⟨contenido⟩>
|   |       <⟨formulario⟩ value={su **borrador**}>    code({su borrador})
|   |         <⟨encabezado⟩ tamano=«"pequeño"»>Editar {el **título** de su **receta**}</⟨encabezado⟩>    code({el título de su receta})
|   |         <⟨campo⟩ etiqueta=«"Nombre de la receta"»>
|   |           <⟨entrada⟩ name=«"título"» class=«"edit-title"» tamano=«"grande"»/>
|   |         </⟨campo⟩>
|   |         <⟨campo⟩ etiqueta=«"Para"» en-linea>
|   |           <⟨entrada⟩ class=«"serves"» name=«"porciones"» type=«"number"» min=«"1"» etiquetado=«"derecha"» etiqueta=«"personas"»/>
|   |         </⟨campo⟩>
|   |         <⟨campo⟩ etiqueta=«"Notas"»>
|   |           <área-texto name=_"notas"_ rows=_"2"_/>
|   |         </⟨campo⟩>
|   |       </⟨formulario⟩>
|   |     </⟨contenido⟩>
|   |     <⟨extra⟩>
|   |       <⟨bot⟩ón class=«"save"» tamano=«"pequeño"» color=«"primario"» desactivado={el **título** de su **borrador** es _""_} onClick={aceptar los cambios}>Guardar</⟨bot⟩ón>    code({el título de su borrador es ""}) code({aceptar los cambios})
|   |       <⟨bot⟩ón class=«"cancel"» tamano=«"pequeño"» onClick={olvidar los cambios}>Cancelar</⟨bot⟩ón>    code({olvidar los cambios})
|   |     </⟨extra⟩>
|   |   </⟨tarjeta⟩>

⟪## La caja:  la tarjeta de una receta nueva, y luego una tarjeta por cada receta⟫

[thing create_one_of_a_kind L0]
| «caja de recetas» es una **aplicación**
|   [property define_property_has L1]
|   | su «"búsqueda"» es **texto**
|   [property define_property_has L1]
|   | «"receta nueva"» es **una nueva receta** con **porciones** = «4»
|   [property define_property_has L1]
|   | su «"editando"» es una **receta**
|   |   ⟦// La receta en su pantalla de edición, mientras haya una⟧
|   [property define_menu L1]
|   | su «"menú de la caja"» es un menú de «"deshacer"»

|   [action create_hook L1]
|   | al «crearla»
|   |   ⟦// Si todavía no hay nada guardado, unas cuantas para empezar⟧
|   |   [control if L2]
|   |   | si no hay **recetas**    ‾value(no hay recetas)
|   |   |   agregar (**una nueva receta** con **título** _"Sopa de tomate"_, **porciones** = _4_, **notas** = _"Asa los tomates primero."_) a las **recetas**    ‾value(una nueva receta con título "Sopa de tomate", porciones = 4, notas = "Asa los tomates primero.") ‾value(las recetas)
|   |   |   agregar (**una nueva receta** con **título** _"Dal"_, **porciones** = _6_, **notas** = _"Agrega las especias al final."_) a las **recetas**    ‾value(una nueva receta con título "Dal", porciones = 6, notas = "Agrega las especias al final.") ‾value(las recetas)
|   |   |   agregar (**una nueva receta** con **título** _"Pizza Margarita"_, **porciones** = _2_, **notas** = _"El horno bien caliente."_) a las **recetas**    ‾value(una nueva receta con título "Pizza Margarita", porciones = 2, notas = "El horno bien caliente.") ‾value(las recetas)

|   [property property_value_getter L1]
|   | su «"coincidencias"» es
|   |   ⟦// Las más nuevas primero, por cuándo se guardó cada una⟧
|   |   devolver cada **receta** donde su **título** incluye la **búsqueda**, ordenadas por su **creado**, de más reciente a más antiguo    ‾value(cada receta donde su título incluye la búsqueda, ordenadas por su creado, de más reciente a más antiguo)

|   [action to_do_something L1]
|   | para «agregar la receta nueva»
|   |   agregar la **receta nueva** a las **recetas**    ‾value(la receta nueva) ‾value(las recetas)
|   |   fijar su **receta nueva** a **una nueva receta** con **porciones** = _4_    ‾value(su receta nueva) ‾value(una nueva receta con porciones = 4)

|   |   <⟨contenedor⟩>
|   |     <⟨pila⟩ direccion=«"horizontal"» ajustar alinear=«"fin"» repartir=«"entre"»>
|   |       <⟨pila⟩ alinear=«"inicio"»>
|   |         <⟨encabezado⟩ tamano=«"grande"»>Caja de recetas</⟨encabezado⟩>
|   |         <⟨texto⟩ color=«"gris"»>Todo lo que escribes se guarda al instante.</⟨texto⟩>
|   |       </⟨pila⟩>
|   |       <⟨barra-herramientas⟩ class=«"undo"» menu=«"menú de la caja"» aria-label=«"Recetas"»/>
|   |       <⟨formulario⟩ value={eso} class=«"find"» fluido>    code({eso})

|   |         </⟨campo⟩>
|   |       </⟨formulario⟩>
|   |     </⟨pila⟩>
|   |     {dibujar la **pantalla** de eso}

|   [action draw_it L1]
|   | para **dibujar** su **pantalla**
