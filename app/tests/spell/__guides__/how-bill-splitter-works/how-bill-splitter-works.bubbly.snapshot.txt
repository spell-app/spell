==== /HowBillSplitterWorks.spell
⟪# How the Bill Splitter works⟫
⟦// The Bill Splitter example works out who owes what after a meal:⟧
⟦// each person pays for what they ordered, plus their share of the tip.⟧
⟦// Change any amount, and every sum on the page follows at once.  Two ideas make that happen:⟧
⟦// - the sums are RULES:  worked out from the amounts, never typed in, so they can't fall behind⟧
⟦// - the boxes you type in are a FORM bound to the bill:  typing in one changes the bill itself⟧

⟦// This guide splits a bill evenly instead, so the whole thing fits on one screen.⟧
⟦// Open Bill Splitter, in the Examples, for one line per person.⟧

⟪## Money:  a number written as dollars and cents, e.g. 12.5 => "$12.50"⟫
⟦// The same lines as the example's `Money.spell`.⟧
⟦// - `round` drops anything smaller than a cent.⟧
⟦// - The last two lines add a 0 when the cents are under ten, so 3.07 doesn't show as $3.7.⟧

[action to_do_something L0]
| to «write (amount as a number) as money»    ‾value(amount as a number) bold(amount) bold(number)
|   set **cents** to round (**amount** * _100_)    ‾value(cents) ‾value(round (amount * 100))
|   set **dollars** to (**cents** / _100_) as an integer    ‾value(dollars) ‾value((cents / 100) as an integer)
|   set **left over** to **cents** - **dollars** * _100_    ‾value(left over) ‾value(cents) ‾value(dollars)
|   if **left over** < _10_ return _"$"_ + **dollars** + _".0"_ + **left over**    ‾value(left over) ‾value(dollars) ‾value(left over)
|   return _"$"_ + **dollars** + _"."_ + **left over**    ‾value(dollars) ‾value(left over)

⟪## The bill⟫
⟦// What the three boxes hold, each a number with what it starts at:  a $60 dinner for three, with an 18% tip.⟧
⟦// Then the sums, each worked out from the lines above, every time one of them changes.⟧

⟦// The tip is a percent, `type="percent"`:  Spell keeps 18% as its fraction, 0.18,⟧
⟦// so `the amount * the percent` is the tip, with no `/ 100`;  its box, `<input type="percent">`, shows 18.⟧

⟦// `<form value={it}>` binds the form to the bill:  each box's `name` is the property it changes.⟧
⟦// The sums show as Spell UI's `<statistic>`s:  a big value, its label under it.⟧

[thing create_one_of_a_kind L0]
| «bill» is an **app**
|   [property define_property_has L1]
|   | its «"amount"» is a **number** starting at «60»
|   [property define_property_has L1]
|   | its «"percent"» is a percent starting at «18%»
|   [property define_property_has L1]
|   | its «"people"» is a **number** starting at «3»

|   [property property_value_getter L1]
|   | its «"tip"» is the **amount** * the **percent**
|   [property property_value_getter L1]
|   | its «"total"» is the **amount** + the **tip**
|   [property property_value_getter L1]
|   | its «"each"» is
|   |   _0_ if the **people** < _1_    ‾value(the people)
|   |   the **total** / the **people** otherwise    ‾value(the total) ‾value(the people)

|   [action to_do_something L1]
|   | to **draw** it
|   |   <⟨container⟩ text>
|   |     <⟨segment⟩>
|   |       <⟨form⟩ value={it}>    code({it})
|   |         <⟨stack⟩>
|   |           <⟨input⟩ name=«"amount"» type=«"number"» min=«"0"» step=«"0.01"» label=«"Bill $"» fluid/>
|   |           <⟨input⟩ name=«"percent"» type=«"percent"» min=«"0"» label=«"Tip %"» fluid/>
|   |           <⟨input⟩ name=«"people"» type=«"number"» min=«"1"» label=«"People"» fluid/>
|   |         </⟨stack⟩>
|   |       </⟨form⟩>
|   |       <⟨divider⟩/>
|   |       <⟨statistics⟩ widths=«"3"» size=«"small"»>
|   |         <⟨statistic⟩ value={write the **tip** as money} label=«"Tip"»/>    code({write the tip as money})
|   |         <⟨statistic⟩ value={write the **total** as money} label=«"Total"»/>    code({write the total as money})
|   |         <⟨statistic⟩ value={write the **each** as money} label=«"Each"» color=«"green"»/>    code({write the each as money})
|   |       </⟨statistics⟩>
|   |     </⟨segment⟩>
|   |   </⟨container⟩>

⟪## Checks⟫

|   write _12.5_ as money should be _"$12.50"_    ‾call(write 12.5 as money)
|   write _3.07_ as money should be _"$3.07"_    ‾call(write 3.07 as money)

[action to_do_something L0]
| to «test splitting»
|   the **total** of **bill** should be _70.8_    ‾value(the total of bill)
|   write the **each** of **bill** as money should be _"$23.60"_    ‾call(write the each of bill as money)
