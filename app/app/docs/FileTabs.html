FileTabs The open project's files, as tabs over the code, and a button at their end listing them all.

Every file of the open project, as a tab over its code. Clicking a tab shows that file. When some files aren't tabs you can see, a button at the end of the row lists every one of them.

Written for: anyone changing the spell app's editor, or reading its code A picture, not live: it needs the whole editor around it

InputEditor's code column draws it over the code (<FileTabs />, no props):

  • The tabs themselves are Spell: the file tab bar of the editor's own Spell, SpellEditor.spell. This component hands it the project's files, and what showing one does.
  • Which files there are, and which is showing, come from trackProjectFiles(), in the same file.
  • More than eight files: the ones opened lately are tabs, the rest only in the all-files list. A tab's ✕, or a middle click, closes it.
  • A tab dragged along the row moves its file there, in the project's file order.
  • A tab's right-click menu: Duplicate, Rename, Delete and the app's actions.
  • The ✕ at the row's far right hides the code, as the top bar's code icon does.
