CodeMirrorEditor A CodeMirror editor, filling its parent: what every code editor in the app is.

CodeMirror 6, as a Solid component that fills the box it's in. Every code editor in the app is one: the code pane, the Inspector's Code card, the compiled-code pane, Publish's diff, a notebook's cells, and the editor in a <spell-editor>.

The compiled-code pane (CodeOutputPane) draws one on the project's compiled code, read only. It loads it lazily, so it goes inside a <Loading> that shows "Loading editor…" till it's in:

CodeOutput.tsx · the compiled code · 8 lines
  • Only the editor's pages need CodeMirror, so it's never imported directly: the app loads it after the program has compiled and run, through LazyCodeMirror, and a <spell-editor> through its own loader.
  • What it shows:
    • state, someone else's, which wins: a file's, from the app's FileStates; the FileEditor shows each file's state in one view
    • else value, in a state of its own: with extensions, or as language says (compiled code, read only, its lines numbered; or a snippet of Spell)
  • It's made once, when it's settled into the page: remount it for a fresh editor. A file's editor doesn't: it shows each file's state in the same view.
  • A new value goes in only if it differs, as a new starting point: undo can't go back past it, and onChange isn't called. That's only for the person's own edits.
  • onMount and onUnmount hand out the view itself, to show a file in it or follow the caret.
  • It works inside a shadow root too, as in a <spell-editor>: the view's root is the element's.
