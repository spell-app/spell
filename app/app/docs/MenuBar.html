MenuBar The top bar's menus: Spell's, listing the group's projects, then the project's, File, Edit, View, Run and Help.

The menus along the editor's top bar. The first, the Spell menu, is how you move between projects: it lists every project of the group the open one is in (the Examples, or the Guides), the one shown ticked.

Written for: anyone changing the spell app's editor, or reading its code A picture, not live: it needs the whole editor around it

The editor page draws them in its top bar, each in a slot of the editor's own Spell:

  • <SpellBarMenu>: the Spell menu. Home and About Spell at its top, then the project list (<ProjectsMenu>, inside the same file), in columns of 10 when there are more, New Example last. In Run, the project chosen opens in Run.
  • <ProjectBarMenu>: the open project's own menu, under its name, with its Theme items.
  • <AppBarMenus>: File, Edit, View, Run and Help, folded into one menu when the window is narrow.
  • The project list reads its group through trackProjectRoot(), and opens one with openProject(): the landing page's cards read the same.
