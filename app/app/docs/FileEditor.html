FileEditor A CodeMirror editor on one Spell file at a time, kept in step with it.

Where you type spell in the editor: a CodeMirrorEditor showing one file. What you type goes straight into the file, and a file loaded or reloaded shows in the editor.

Written for: anyone changing the spell app's editor, or reading its code A picture, not live: it edits the editor's open file

The editor's input pane, on the Solitaire example's cards: everything under the toolbar is a FileEditor on the open file.

A picture, taken by yarn site:pictures in spell-app.

The InputEditor draws one, once CodeMirror has loaded, and shows each file in it:

InputEditor.tsx · the code pane's editor, shortened · 9 lines
  • It shows the file's CodeMirror state, which the app's FileStates keep in step with the file both ways.
  • With no file yet, it says the editor's loading.
  • A new file shows in the same view, and the last one's state is kept: its undo, folds, selection and scroll, so switching back finds it as it was left. No remount per file.
  • onMount hands out the editor, SpellCodeMirror, once it shows a file: the app follows its scrolling there, and its caret through onUpdate. Its keys are the page's, passed in as hotkeys.
  • Only the editor's pages need CodeMirror, so it's loaded after the program has compiled and run: draw it through LazyCodeMirror, inside a <Loading>, never by importing it.
