<epic-pills> The <epic-pills> element: the docs home page's Active epics, a live pill per epic worked on this week.

<epic-pills> is the Active epics list on the docs home page's Epic Pages card. Each pill shows an epic's name, what waits on it, its phase and its agents. It asks the page server, so it stays up to date all night.

Written for: anyone changing the docs home page, or this element.
Status: built (epic epic-engine T99), in the epic-pills folder of the epics package.
Its vocabulary (parts, texts): EpicPills.en.ts.
The component: EpicPills.tsx.

The example above · 1 line

The active epics, live from this page server. Opened from disk, it says it needs the page server instead. With no epic worked on this week, it says so.

epic pages index writes it into the home page's Epic Pages card, under the card's description. Nothing goes inside it: the pills come from the page server.

In the docs home page's Epic Pages card (pages/index.html), once. It works on any served page. It has no children and no attributes.

Pieces of what it draws, which a page's CSS can style from outside with ::part(name).

Part What it is
base The box around the heading and the pills.
heading The heading: Active epics.
pills The pills, in two columns.
note Instead of pills: none this week, the page opened from disk, or no answer.
  • Which epics: the Epics page's Active group, worked on in the last 7 days, A to Z by name.
  • Each pill is a small round blue label. A click opens the epic page in this tab.
  • The epic's name is on the left. It is cut short with "…" when there's no room.
  • On the right, what waits on the epic, in the colours of its epic page's toolbar badges: red for urgent, orange for your turn to pick or review (light orange counts as orange), blue for phases running. One colour shows its count. Several colours show one circle split between them, with no number.
  • Then the phase under way, P12, or Done when every phase is done.
  • Then the running agents, a robot and their number, when any run.
  • The tooltip says it all in words: the counts, the phase's name and the agents.
  • Two columns, at the card's width and in the side bar's. Pills are 24px tall, 4px apart.
  • epic pages index: the home page's generator writes the tag, and nothing else.
  • What it draws comes from the page server, GET /api/epics/running?every (RunningEpics): every epic, running or not, with what waits on it and how many agents run. It asks again whenever an epic page or its agents change, and every 30 seconds.
  • Until epic epic-engine T99, the generator wrote a plain pill per epic into the page (J276), as of when it last ran.
