<epic-state-filter> The <epic-state-filter> element: the state filter's chips, a pill per item state with how many, solid while it shows.

<epic-state-filter> is the state filter's chips: a pill per state the items are in, in the state's colour, with how many. Solid while that state's items show, outlined while hidden.

  • It filters nothing itself: a click tells its owner what was picked, and what should show next.
  • ONE element for every filter by state: an item section's title, an epic page's toolbar, the Epics page's lists.

For anyone changing how items are filtered.
Status: built (epic epic-engine P3), in the epic-state-filter family, with <epic-hidden-note>.
Its vocabulary: EpicStateFilter.en.ts
Its component: EpicStateFilter.tsx.

Red and yellow show, green is hidden. A click here only says so: nothing on this page listens.

Nobody writes it in a doc: <epic-section> and <epic-page> draw it in their shadow roots, and the docs runtime puts one in a section's title on the Epics page (wireItemFilters()).

AttributeWhat it is
countsHow many items are in each state: attention:2 open:5. A chip per state with any, in the filter's order: progress, attention, replied, open, recent, old.
shownThe states showing. No attribute: every state; "": none.

What it tells its owner.

EventDetailWhen
epic-state-changed{ state, shown }A chip was clicked: its state, and what should show next by the one rule (StateFilter.nextShown()).
  • Each state in its colour: blue Claude is on it, red needs Owen, orange his turn to pick, yellow open, green done lately, grey older.
  • The colours come from the page: an epic page's --epic-state-*, a docs page's --spell-state-*.
  • Each chip's tooltip says how many, which state, and what a click does.
  • <epic-section>, <epic-page> and the docs runtime (before epic epic-engine P3, each drew its own chips).
