<epic-test-run> The <epic-test-run> element: an epic page's open tests, one at a time, each answered on the page.

<epic-test-run> is a TEST RUN: it steps Owen through an epic page's open tests, one big card at a time, and he answers each on the page: Passed, Failed, Skip or Not now, with a comment and a screenshot on any of them. The listening session closes the passed ones and files each failure as an issue.

For anyone changing how hand checks are run, or how a test is written.
Status: built (epic epic-engine P4), the epic-test-run family.
Its vocabulary: EpicTestRun.en.ts
Its component: EpicTestRun.tsx; what it reads from the page: TestRun.ts.

A run over a sample page's two tests, the first in the new shape, the second an older one (prose only). This page isn't reviewed, so the answers are disabled and say why; on a served epic page they're marks.

Nobody writes it in a doc: <epic-page> draws it over its blocks in TEST MODE, which starts from:

  • the To test section's Start testing · 9, on its title (<epic-section>, while the page is reviewed and a test is open)
  • the page's address: ?test=1 (epic test <epic>), and #v3 lands on that test
  • ?test=1&all=1: one epic of a run across every epic (epic test --all), its summary leading to the next

Esc or Done testing leaves it, the blocks back, ?test off the address. Its place stays in the address (#v3): a reload resumes there.

LEAVING SENDS (I52): Done testing, Esc and the summary's next epic hand the run's unsent answers to Claude (the page's Send, as Send results does), and the notice line at the window's foot says so: "3 results sent to Claude". Nothing answered: it just leaves. The send failing (the page server gone, a file:// page): the notice says so, and the answers wait, Send blue in the header.

Each a review mark on the test, { action: "test", result, note?, shot? }, sent with Send like any mark, or by leaving the run. Not one by one as given: each send wakes a waiting session, so a run of 17 tests would wake it 17 times.

A COMMENT box on every card, under the answers ("Comment (optional)"): it goes with whichever answer he picks, typed before or after choosing, and stays when he changes the answer. Kept as he types: in the answer's note, or, before an answer, the inbox's draft for the test, so a reload keeps it. epic inbox apply puts it on the test as his reply; the summary lists the tests commented on.

← and → move; Esc leaves, sending the answers. An answered test shows its answer, dashed until sent, outlined once sent, and takes another.
