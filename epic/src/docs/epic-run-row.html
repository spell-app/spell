<epic-run-row> The <epic-run-row> element: one row of a run page: the command's columns, then Owen's answer.

One row of a run page: a thing a command asks about, and Owen's answer to it.

For anyone writing a command that asks Owen on a page, or changing this element.
built in epic-run-row/ (epic epic-engine P23).
Its vocabulary (every name it uses): EpicRunRow.en.ts.
Its component: EpicRunRow.tsx, with its style sheet (.css) and tests beside it.

Two rows, as a run page draws them: one with alternatives, one with a tick box and details.

Live: the real element, drawn by the epics pack this page loads. Outside a run page nothing saves.

Never written in a page: <epic-run> draws one per row in its shadow root, giving it the row, the columns and Owen's answer as properties. In markup, they're JSON.

  • Its parent: <epic-run>'s table, in its shadow root.
  • Its children: none.
Name Values Meaning Required
row a RunRow The row, as the command wrote it: id, cells, value (the proposal), alternatives, tick, details. yes
columns a list of { key, label } Which cells to show, in order. no
answer a RunAnswer Owen's answer so far; none: the proposal. no
answer-label text The answer column's name: the box's name for a screen reader. no
taken a time, ISO When the command took the row (acted on it; epic epic-engine P25). An answer saved after it shows the orange note. no
Event Sent when
epic-run-answered Owen typed (now: false), picked or ticked (now: true); outcome: accepted, picked or typed.
  • Its cells on the table's columns; the answer cell holds the box, the pick, the tick box, the details.
  • The pick: small pills, the proposal's dashed until chosen; the chosen one raised and inked, as a segmented control's thumb.
  • Answered differently from the proposal: an orange box, an orange edge, and a round button back.
  • Taken by the command: a quiet check and taken beside the box, the time in its tooltip.
  • Changed after it was taken: an orange note under the box, changed after the run took it; the command may still pick the change up.
  • Nobody: <epic-run> draws it, from the run's run.json5.
