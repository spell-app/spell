# Sound attribution

The sounds in `src/sounds/sound-library/` (shipped beside the code that plays them, as `sound-library/`) are
139 sounds picked from seven of [Kenney](https://kenney.nl)'s free audio packs, by Kenney Vleugels,
copied unchanged as Kenney made them (Ogg Vorbis).  Each file is renamed for the sound's English name in Spell.

- Licence:  [Creative Commons Zero, CC0](https://creativecommons.org/publicdomain/zero/1.0/), public domain.
- Kenney's own words, in every pack's `License.txt`:
  "You may use these assets in personal and commercial projects.
  Credit (Kenney or www.kenney.nl) would be nice but is not mandatory."
- Downloaded 2026-11-17 (epic `mockup` P28).
