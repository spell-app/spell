Calendar A calendar lets a user pick a date, a time, or both.

A standard calendar: a date and a time, Fomantic's default type. The field takes typed text too; the icon button opens the picker.

A range calendar allows you to select a start date and a stop date: end-calendar names the end's calendar, start-calendar the start's. Each limits the other, and the days between them are highlighted.

An inline calendar isn't shown in a popup: no field, no popup, still a form control. Name it with aria-label.

Multimonth (several day grids side by side, multiMonth / monthOffset) can't be drawn yet: a calendar shows one grid (plan issue I63).

position says where the popup opens against the field; it flips when there's no room.

The type and the date are HTML attributes: value is an ISO string in the shape of the type, e.g. 2019-12-24.

A year first calendar allows you to select a date by starting to select a year. Ours opens on the days; its title button goes up to months and years.

You can get rid of the AM/PM notation with a locale that uses a 24-hour clock (en-GB, de-DE ...).

You can set a minimum and a maximum selection date: min and max, ISO like the value. Days outside stay focusable, but can't be picked.

Day first display (parsing too) follows the locale: en-GB reads and writes 30/09/2026.

Custom format (token strings such as YYYY-MM-DD, or a function) and Century Calculation for shortyears can't be set yet: the field uses the locale's own format (plan issue I65).

It's possible to change the calendar language to fit with your needs: locale sets month and day names, formats, the clock and the first day of the week (unless first-day-of-week says, 0 = Sunday). The Today / Now and button names follow the page's translations.

Button (a calendar opened from a ui button, with no text field) can't be built yet: a calendar always draws its own field (plan issue I66). An inline calendar inside a <ui-popup> is the nearest thing. Not ported: Context (context / popupContext) -- the picker is a popover in the top layer, so an overflowing container never clips it.

Disable each Monday, Wednesday and Friday from selection: disabled-days-of-week, a JSON array (0 = Sunday), or the disabledDaysOfWeek property.

Disabling specific single dates: disabled-dates, a JSON array of ISO dates, or the disabledDates property. Fomantic's optional reason popup on hover isn't there yet.

Hours, Whole Months, Whole Years and Enable only specific Dates can't be set yet: only dates and weekdays can be disabled (plan issue I68).
