Theme Look Restyles
spell Spell's own look, from the Spell brand: Palatino-family serif headings with italic ledes, a system sans body, Spell Purple, pill buttons, 16px cards, soft layered shadows, an aubergine dark mode. This site's default; page-wide. everything, through the global tokens
glass macOS today: the system font, rounded rectangles, Apple's system colours, and translucent glass surfaces that blur what's behind them, on a solid page. Page-wide. everything, through the global tokens
fruity Glass over a soft pastel wallpaper: three blurred colour washes behind the page. Page-wide. everything, through the global tokens
merlot A code studio in wine reds: flat panels on hairlines a step off the page, no glass; an amber primary on deep wine in dark, a maroon one on rose-grey in light. Page-wide. everything, through the global tokens
classic Fomantic's original look, and the base of every theme above: Lato, 14px, Fomantic's palette and size ratios, 4px radii. Page-wide. everything, through the global tokens

Every colour derives from a few base tokens: re-point --ui-primary or a hue's per-scheme base, and its hover, focus, down and active states, its text, border and background roles follow. Edit a value below to try it on these buttons.

These tokens are Fomantic's site variables (@primaryColor, @red ...). A hue's base is a light-dark() pair of tokens: re-colour both, --ui-red-on-light and --ui-red-on-dark, to keep dark mode. Primary Button Secondary Button Red Green Blue

Components inherit the global tokens and redefine what's theirs in public --ui-<tag>-* tokens, e.g. checkboxes in your brand colour instead of grey. Each component page lists its tokens on its Theming tab.

ui-violet on a wrapper re-points --ui-color: the uncoloured components inside turn violet.

A plain element is the wrapper here: a coloured container component (<ui-segment color>, a card, a message) resets the generic tokens for its content on purpose, so its own colour never leaks into what it holds.
