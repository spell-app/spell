Tree A tree shows rows nested in rows, which open and close, and can be selected one or many at a time.
  • Each strip shows only its pick's name, as few strips as it takes.
  • The last two columns never narrow, nor the selected row's: narrow-before says how many at the end stay wide.
  • Point at a strip to see its column whole.
  • With sticky-path, the line above the columns names each pick: click one to pick it again, keeping the columns after it.
  • The tree hands it the picked row as its item property, and sends ui-changed, so any element can draw it: here a <ui-json>.
  • It's drawn only while something is slotted and something is picked, tight against the last column, as wide as its content.
  • Drag the line after it to resize it; double-click the line to fit its content again.
  • sticky-detail keeps it in view while the columns scroll sideways.
  • With an id and no path set, the tree opens where you left it after a reload, and keeps the pane's width.
