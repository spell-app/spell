A menu can be fixed to a side of its context: fixed is top, bottom, left or right (with vertical for the sides).

A fixed menu sticks to the browser viewport, so this example is code only. For a menu that sticks only while scrolling past, use <ui-sticky>.

A menu can stack at mobile resolutions.

Stackable menus are intended to be used with only simple menu content.
